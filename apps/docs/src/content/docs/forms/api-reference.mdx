# API Reference

## FormComposer

```ts
class FormComposer<TElements, TRecipes, TActions> {
	addElement(registration: InputRegistration | StaticRegistration): this;
	addRecipe(registration: RecipeRegistration): this;
	addAction(registration: BuilderActionRegistration): this;
	addElements(registrations: Array<InputRegistration | StaticRegistration>): this;
	addRecipes(registrations: RecipeRegistration[]): this;
	addActions(registrations: BuilderActionRegistration[]): this;
	build(): FormEngine<TElements, TRecipes, TActions>;
}
```

## FormEngine

`FormEngine` retrieves registered elements, recipes, and actions; validates
`FormConfig` values; and generates JSON Schema and authoring catalog artifacts.

```ts
engine.getElement('text');
engine.getRecipe('card');
engine.getAllRecipes();
engine.validateForm(config);
engine.getFormConfigStandardSchema();
engine.describeViewCatalog();
```

## RecipeRegistration

```ts
interface RecipeRegistration<TType, TConfig> {
	$type: TType;
	kind: 'single-step' | 'wizard';
	slots: Array<'shell' | 'header' | 'progress' | 'actions'>;
	schema: StandardSchemaV1<TConfig>;
	metadata: RecipeMetadata;
	render: unknown;
}
```

Forms select at most one recipe with `view.$type`. Slot configuration is
validated against the selected recipe's schema.
