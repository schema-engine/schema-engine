# Core Concepts

Schema Engine separates serializable form data from framework rendering. The
core package registers elements, view recipes, and actions; an adapter renders
the selected recipe.

## Registration

```ts
const engine = new FormComposer()
	.addElement(textInputRegistration)
	.addRecipe(cardRecipe)
	.addAction(submitActionRegistration)
	.build();
```

## Form configuration

```ts
const config = engine.defineForm({
	id: 'contact',
	title: 'Contact',
	steps: [{ id: 'details', title: 'Details', elements: [] }],
	view: {
		$type: 'card',
		shell: { maxWidth: 'md' },
		header: { showDescription: true },
	},
});
```

`view.$type` selects one registered recipe. The recipe determines its kind and
allowed slots. Single-step recipes require exactly one step; wizard recipes
require at least two. A single-step form may omit `view` to render fields
directly.

`validateForm` parses the form schema, resolves the recipe, validates slot
configuration, and reports all view-specific issues together.
