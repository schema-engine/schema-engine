# Getting Started

Install the framework-agnostic package and `zod`:

```bash
pnpm add @schema-engine/forms zod
```

Register the elements, recipes, and actions used by the application:

```ts
import { createFormEngine } from '@schema-engine/forms';

const engine = createFormEngine({
	elements: [textInputRegistration],
	recipes: [cardRecipe],
});
```

Then define a form. `defineForm` returns a frozen `NormalizedFormConfig`. The
adapter owns rendering and receives the same engine instance so it can resolve
`view.$type`.

```ts
const form = engine.defineForm({
	id: 'contact',
	steps: [{ id: 'details', title: 'Details', elements: [] }],
	view: { $type: 'card' },
});
```

Use `engine.getFormConfigStandardSchema()` when configurations must be
validated outside the runtime.
