# Getting Started

Install the framework-agnostic package and `zod`:

```bash
pnpm add @schema-engine/forms zod
```

Register the elements, recipes, and actions used by the application:

```ts
const engine = new FormComposer().addElement(textInputRegistration).addRecipe(cardRecipe).build();
```

Then define a serializable form. The adapter owns rendering and receives the
same engine instance so it can resolve `view.$type`.

```ts
const form = engine.defineForm({
	id: 'contact',
	steps: [{ id: 'details', title: 'Details', elements: [] }],
	view: { $type: 'card' },
});
```

Use `engine.getFormConfigStandardSchema()` when configurations must be
validated outside the runtime.
