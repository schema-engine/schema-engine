# Getting Started

<FormRendererPreview config={contactFormConfig} />

## 1. Install peers

```bash
pnpm add @schema-engine/forms-radiant @schema-engine/forms @ecopages/radiant-ui @ecopages/radiant @ecopages/jsx @ecopages/signals zod
```

Load Radiant UI theme and styles once in your app entry:

```typescript
import '@ecopages/radiant-ui/themes/default';
import '@ecopages/radiant-ui/styles.css';
```

## 2. Create a form engine

Default field registrations ship in the package:

```typescript
import { createRadiantFormEngine, schemaFormRegistrations } from '@schema-engine/forms-radiant';

const formEngine = createRadiantFormEngine({ elements: schemaFormRegistrations });
```

## 3. Configure your form

Use the same `FormConfig` JSON as the React adapter:

For TypeScript authored next to your engine, prefer
[`engine.defineForm()`](/docs/forms/builder#author-form-configuration).
See [Authoring modes](/docs/forms/core-concepts#authoring-modes).

```typescript
import type { FormConfig } from '@schema-engine/forms/schemas';

const formConfig: FormConfig = {
	id: 'contact-form',
	steps: [
		{
			id: 'step-1',
			elements: [
				{
					$type: 'input',
					id: 'name',
					name: 'name',
					label: 'Full Name',
					rules: [{ type: 'required', message: 'Name is required' }],
				},
				{
					$type: 'input',
					id: 'email',
					name: 'email',
					label: 'Email',
					inputType: 'email',
					rules: [
						{ type: 'required', message: 'Email is required' },
						{ type: 'email', message: 'Invalid email' },
					],
				},
				{ $type: 'submit', id: 'submit', name: 'submit', label: 'Send' },
			],
		},
	],
};
```

## 4. Render the form

```typescript
import { FormRenderer } from '@schema-engine/forms-radiant';

<FormRenderer
	engine={formEngine}
	config={formConfig}
	onSubmit={(data) => console.log(data)}
/>;
```

## Override a registration

```typescript
import { InputElementRegistration } from '@schema-engine/forms-radiant/registrations';

const engine = createRadiantFormEngine({
	elements: [...schemaFormRegistrations, { ...InputElementRegistration, render: MyCustomInput }],
});
```

## Server-rendered forms and engine binding

The engine is not serialized into server-rendered markup. Importing
`@schema-engine/forms-radiant` defines the form elements, which upgrade the
forms already in the document before an engine exists. To give them an engine,
bind first and define after: defer the definitions, import the package and your
engine, make the engine reachable, then define.

```typescript
const { deferFormElements, defineFormElements } = await import('@schema-engine/forms-radiant/define');
deferFormElements();

// Dynamic imports only: static imports are hoisted above deferFormElements().
const [{ formEngine }, { formEngineContext }] = await Promise.all([
	import('./form-engine'),
	import('@schema-engine/forms-radiant'),
]);

document.querySelectorAll('se-form-renderer').forEach((renderer) => {
	renderer.engine = formEngine;
});
defineFormElements();
```

Instead of assigning `engine` to each renderer, you can answer the
`formEngineContext` request from the document, as the docs site does in
`apps/docs/src/lib/preview-engine-binding.ts`. A form that is only rendered on
the client passes `engine` to `FormRenderer` and needs none of this.
