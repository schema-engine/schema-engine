# @schema-engine/forms-radiant

Radiant/JSX implementation of the JSON Form Engine for Ecopages apps. It wraps `@ecopages/radiant-ui` primitives and ships default field registrations in the package (no shadcn copy step).

## Key features

- **Same `FormConfig` JSON** as `@schema-engine/forms-react`
- **One engine form container** with Schema Engine validation rules
- **Default registrations** for input, textarea, number, select, checkbox, switch, radio, and submit
- **Shared Zod Mini schemas** from `registry/shared/forms/*.types.ts`
- **`createRadiantFormEngine()`** — same builder API as the React adapter
- **Scoped `FormController`** for form state and `FormEngineController` for the nearest renderer engine; explicit lifecycle or optional `@formController` decorator

## When to use

| Use                                                | Package                        |
| -------------------------------------------------- | ------------------------------ |
| React + shadcn consumer-owned fields               | `@schema-engine/forms-react`   |
| Radiant / `@ecopages/jsx` + `@ecopages/radiant-ui` | `@schema-engine/forms-radiant` |

## Programmatic form access

Import `FormController`, `FormEngineController`, and `formController` from
`@schema-engine/forms-radiant/adapters/radiant`. Create `new FormController(host)`
for a host inside the form's `se-form-instance`, call `connect(listener)` on connection, and call
`disconnect()` on disconnection. Radiant elements can declare
`@formController form!: FormController` for automatic lifecycle wiring.

Create `new FormEngineController(host)` for a host inside `se-form-renderer`.
Its `engine` and `ready` getters expose the nearest renderer engine, while
`connect()` and `disconnect()` manage the context subscription.

Use `getValue(path)` / `getValues()` for snapshots, `select(selector)` for a signal over
the container's snapshot, and `fieldArray(path)` for array edits. Values are nested and
paths are dotted (`contacts.0.email`), the engine container's own shape. Shipped
`FormFieldElement` extends Radiant UI's field element; array components use the container's
row ids.

The former `useFormContext`, `useFormField`, `useWatchField`, `useWatchForm`,
`useFieldArray`, and `getActiveFormStore` exports have been replaced by this scoped
API. Radiant rendering uses `FormProvider` directly and does not emulate React hooks.
