# @schema-engine/forms-radiant

Radiant/JSX implementation of the JSON Form Engine for Ecopages apps. It wraps `@ecopages/radiant-ui` primitives and ships default field registrations in the package (no shadcn copy step).

## Key features

- **Same `FormConfig` JSON** as `@schema-engine/forms-react`
- **Signals-based `FormStore`** with validation through `@schema-engine/forms`
- **Default registrations** for input, textarea, number, select, checkbox, switch, radio, and submit
- **Shared Zod Mini schemas** from `registry/shared/forms/*.types.ts`
- **`createRadiantFormEngine()`** — same builder API as the React adapter
- **Full field-array operations** through the adapter-neutral `useFieldArray` hook, with stable row IDs during insertion and reordering

## When to use

| Use                                                | Package                        |
| -------------------------------------------------- | ------------------------------ |
| React + shadcn consumer-owned fields               | `@schema-engine/forms-react`   |
| Radiant / `@ecopages/jsx` + `@ecopages/radiant-ui` | `@schema-engine/forms-radiant` |
