# Components

`@schema-engine/forms-react` renders element registrations, but the field
implementations are consumer-owned registry code. Install the matching Schema
Engine registry item and import its generated registration barrel:

```ts
import { createFormEngine } from '@schema-engine/forms-react';
import { schemaFormRegistrations } from '@/components/schema-engine/forms/registrations';

const engine = createFormEngine({ elements: schemaFormRegistrations });
```

## Registry elements

The aggregate `schema-form` item currently includes:

| `$type`                       | Purpose                                                |
| ----------------------------- | ------------------------------------------------------ |
| `input`                       | Text, email, password, URL, telephone, and date inputs |
| `textarea`                    | Multi-line text                                        |
| `number`                      | Numeric input                                          |
| `select`                      | Select menu                                            |
| `checkbox`, `checkbox-group`  | Boolean and multi-choice inputs                        |
| `radio`                       | Single-choice group                                    |
| `switch`                      | Boolean toggle                                         |
| `slider`                      | Numeric range                                          |
| `combobox`                    | Searchable choice input                                |
| `drop-zone`                   | File drop input                                        |
| `fieldSet`                    | Grouped content                                        |
| `input-otp`                   | One-time-password input                                |
| `phone-input`, `masked-input` | Specialized text inputs                                |
| `arrayElements`               | Repeated element groups                                |
| `submit`, `submission-alert`  | Action and submission feedback                         |

The registry item is an installation boundary: applications can select a
smaller set of registrations or replace one registration before building the
engine.

## Element configuration

Every field has a `$type` and `name`; the remaining properties come from that
registration's schema. Shared properties include `label`, `description`,
`defaultValue`, `rules`, `constraints`, `grid`, `className`, and `style`.

```json
{
	"$type": "input",
	"id": "email",
	"name": "email",
	"label": "Email address",
	"inputType": "email",
	"rules": [
		{ "type": "required", "message": "Email is required" },
		{ "type": "email", "message": "Enter a valid email" }
	]
}
```

Responsive placement belongs to the element's `grid` property and the form's
top-level `grid` configuration. View chrome belongs to `view`, not to a step or
element; see [View recipes](/docs/forms-react/layouts).

## Custom elements

Create a consumer-owned registration with `InputRegistration` (or
`StaticRegistration` for display-only content). The render component receives
the registration config and should use `useControlledFormElement` for field
binding:

```tsx
import type { InputRegistration } from '@schema-engine/forms';
import { useControlledFormElement } from '@schema-engine/forms-react';
import * as z from 'zod/mini';

const RatingSchema = z.object({
	$type: z.literal('rating'),
	id: z.string(),
	name: z.string(),
	label: z.optional(z.string()),
	max: z._default(z.number().check(z.int(), z.positive()), 5),
});

function Rating({ ...config }: z.output<typeof RatingSchema>) {
	const { value, onChange, fieldProps } = useControlledFormElement(config);
	return (
		<input {...fieldProps} type="number" value={value ?? ''} onChange={(event) => onChange(event.target.value)} />
	);
}

const ratingRegistration: InputRegistration<'rating', typeof RatingSchema> = {
	$type: 'rating',
	schema: RatingSchema,
	render: Rating,
	metadata: {
		name: 'Rating',
		description: 'Numeric rating input',
		category: 'input',
	},
};

const engine = createFormEngine({ elements: [ratingRegistration] });
```

In a real registry item, make the render props type explicit. The Mini schema
already implements Standard Schema, so it can be passed directly as the
registration schema.
