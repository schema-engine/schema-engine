# Hooks

## View hooks

Recipe shells and blocks can access the active view with:

```tsx
function ProgressBlock() {
	const { steps, currentStepIndex } = useViewContext();
	const navigation = useFormNavigation();
	const activeStep = useActiveStep();
	const config = useViewConfig<{ showPercentage?: boolean }>();

	return (
		<div>
			{activeStep.title}: {currentStepIndex + 1} / {steps.length}
		</div>
	);
}
```

`useViewConfig` reads the configuration for the current recipe slot. It is
available only inside a `ViewProvider` or a slot block rendered by a recipe.

## Form hooks

`useFormContext` exposes adapter-neutral values, errors, submission state, and
field operations. `useFormField` binds an element registration to that form.
`useWatchField`, `useWatchForm`, and `useFieldArray` cover observation and
array editing. `useFieldArray` provides `fields` plus `append`, `prepend`,
`insert`, `swap`, `move`, `update`, `replace`, and `remove`.

## Engine hooks

`useFormEngine` reads the `FormEngine` supplied by `FormEngineProvider`, while
`useFormInstanceActions` exposes current-step and submission actions.
