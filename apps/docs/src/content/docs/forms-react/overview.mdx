# @schema-engine/forms-react

React adapter for the JSON Form Engine. It supplies rendering, hooks, and view
recipe composition while applications supply element registrations.

## Public entry points

- `@schema-engine/forms-react`: rendering components and providers.
- `@schema-engine/forms-react/hooks`: runtime and view hooks.
- `@schema-engine/forms-react/adapters`: adapter contracts and form hooks.
- `@schema-engine/forms-react/adapters/react-hook-form`: `rhfAdapter`, which requires the optional `react-hook-form` peer.
- `@schema-engine/forms-react/primitives`: `FormElement`, `FormElements`, and recipe contracts.
- `@schema-engine/forms-react/contexts`: view provider and context types.

Create engines with `createFormEngine` from `@schema-engine/forms`. Install
consumer-owned registry elements and recipes for your UI library. The rendering
runtime uses `se-*` styling hooks and does not require Tailwind.

Browser consent and analytics helpers live in `@schema-engine/forms/browser`.
