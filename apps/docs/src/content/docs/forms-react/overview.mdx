# @schema-engine/forms-react

The React renderer for [Forms](/docs/forms/overview). It supplies rendering, hooks and view recipe composition, and it ships no element registrations: you write your own widgets with `useFormField`, or copy ready-made ones with the optional [registry fields](/docs/forms-react/components). See [Installation and quick start](/docs/forms-react/getting-started).

## Public entry points

- `@schema-engine/forms-react`: rendering components and providers.
- `@schema-engine/forms-react/hooks`: form state, runtime and view hooks.
- `@schema-engine/forms-react/primitives`: `FormElement`, `FormElements`, and recipe contracts.
- `@schema-engine/forms-react/contexts`: view provider and context types.

Create engines with `createFormEngine` from `@schema-engine/forms` and register the elements and recipes you want. The rendering runtime uses `se-*` styling hooks and does not require Tailwind.

Browser consent and analytics helpers live in `@schema-engine/forms/browser`.
