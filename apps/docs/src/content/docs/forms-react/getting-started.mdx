## 1. Create a Form Engine

Install the form elements and, when using a supplied visual recipe, the recipe source from the Schema Engine shadcn registry:

```bash
pnpm dlx shadcn@latest add andeeplus/schema-engine/schema-form andeeplus/schema-engine/schema-engine-form-recipes
```

The recipes copy their stylesheet with them. Import it once in your global stylesheet, after Tailwind and into the `components` layer (see [View recipes](/docs/forms-react/layouts#default-registry-recipes)):

```css
@import 'tailwindcss';
@import './components/schema-engine/forms/recipes/recipes.css' layer(components);
@import './components/ui/schema-engine/components/controls.css';
```

The path is relative to your global stylesheet: `./components/schema-engine/forms/recipes/recipes.css` from a Vite `src/index.css`, `../components/schema-engine/forms/recipes/recipes.css` from a Next.js `app/globals.css`. The second, unlayered import is the control height of the `size` appearance axis; it comes with the field primitive, and [View recipes](/docs/forms-react/layouts#default-registry-recipes) says why it is not layered.

Then import their generated registration barrels:

```typescript
import { createFormEngine } from '@schema-engine/forms';
import { schemaFormRegistrations } from '@/components/schema-engine/forms/registrations';
import { schemaFormRecipeRegistrations } from '@/components/schema-engine/forms/recipes/registrations';

const formEngine = createFormEngine({ elements: schemaFormRegistrations, recipes: schemaFormRecipeRegistrations });
```

## 2. Configure Your Form

Create a JSON configuration — this page's live demo renders exactly this:

<FormConfigCode config={basicContactFormConfig} />

When the form is authored in TypeScript next to your engine (not loaded from
JSON), use [`engine.defineForm()`](/docs/forms/builder#author-form-configuration)
for compile-time checks. See [Authoring modes](/docs/forms/core-concepts#authoring-modes).

## 3. Render the Form

```tsx
import { FormEngineProvider, FormRenderer } from '@schema-engine/forms-react';

function ContactForm() {
	const handleSubmit = (data) => {
		console.log('Form submitted:', data);
	};

	return (
		<FormEngineProvider engine={formEngine}>
			<FormRenderer config={formConfig} onSubmit={handleSubmit} />
		</FormEngineProvider>
	);
}
```
