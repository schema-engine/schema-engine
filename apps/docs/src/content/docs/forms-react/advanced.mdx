# Advanced Usage

## Conditional fields

Put one or more constraint objects directly on an element. Each object names a
source field, comparison, and effect:

```ts
{
	$type: 'input',
	id: 'other-reason',
	name: 'otherReason',
	label: 'Please specify',
	constraints: [
		{
			field: 'reason',
			operator: 'equals',
			value: 'other',
			action: 'show',
		},
	],
}
```

Supported operators are `equals`, `not_equals`, `contains`, `not_contains`,
`greater_than`, `less_than`, `is_empty`, and `is_not_empty`. Effects are
`show`, `hide`, `enable`, `disable`, and `require`.

## Consent-aware drafts

`useGDPRConsent` manages consent for the core draft-storage helper. It does not
add a `gdpr` property to field configuration.

```tsx
import { useGDPRConsent } from '@schema-engine/forms-react';

function DraftConsent() {
	const consent = useGDPRConsent();

	return consent.hasConsent() ? (
		<button type="button" onClick={consent.revokeConsent}>
			Revoke draft consent
		</button>
	) : (
		<button type="button" onClick={consent.grantConsent}>
			Allow draft storage
		</button>
	);
}
```

Grant consent before using `GDPRConsent.saveDraft`; revoking consent also clears
the package's `form_draft_` entries from local storage. Applications should
still provide their own disclosure and retention policy.

## Analytics

Use `useGTMTracker` for direct data-layer integration:

```tsx
import { useGTMTracker } from '@schema-engine/forms-react';

function TrackSubmit() {
	const tracker = useGTMTracker();

	return (
		<button type="button" onClick={() => tracker.pushFormEvent('form_submit', undefined, { formId: 'contact' })}>
			Track submit
		</button>
	);
}
```

The hook supports `form_mount`, `form_step_complete`, `form_submit`, and
`form_abandon`. Avoid sending sensitive values; the tracker filters common
password, SSN, and credit-card keys, but field-level minimization remains the
application's responsibility.

For config-driven analytics, register the core `gtm_event` action and place an
action config in `form.actions`. See [Actions](/docs/forms/actions) for the
action registration and trigger model.
