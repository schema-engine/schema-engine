# API Reference

## Engine factory

```ts
import { createFormEngine } from '@schema-engine/forms';

const engine = createFormEngine({
	elements: schemaFormRegistrations,
	recipes: [...schemaFormRecipeRegistrations, customRecipe],
});
```

`createFormEngine()` is headless. Register installed default recipes or
your own recipes in the `recipes` array. Use `engine.extend({ recipes: [customRecipe] })`
to add registrations later.

## FormElements

```tsx
import { FormElements } from '@schema-engine/forms-react/primitives';

<FormElements elements={config.elements} namePrefix={config.name} nameStrategy="join" instanceId={itemId} />;
```

Fieldsets pass `namePrefix={config.name}`. Array items pass an
`arrayItemScope` so paths and HTML ids are composed at render time. Do not
clone child configs to change `name` or `id`.

## Rendering

```tsx
import { FormEngineProvider, FormRenderer } from '@schema-engine/forms-react';
import { rhfAdapter } from '@schema-engine/forms-react/adapters/react-hook-form';

<FormEngineProvider engine={engine} adapter={rhfAdapter}>
	<FormRenderer config={formConfig} onSubmit={handleSubmit} />
</FormEngineProvider>;
```

`FormRenderer` validates the config once at the form boundary and renders the
resulting `NormalizedFormConfig`. Field renderers do not re-parse registration
schemas. The selected recipe receives a `ViewContext` containing form metadata,
active-step state, navigation, and the current slot configuration.

## View hooks

```ts
import { useViewContext, useActiveStep, useFormNavigation, useViewConfig } from '@schema-engine/forms-react/hooks';
import { StepHeaderConfigSchema } from '@schema-engine/forms/recipes/built-in';

useViewContext();
useActiveStep();
useFormNavigation();
useViewConfig('header', StepHeaderConfigSchema);
```

Shells and slot blocks are ordinary components. Bind them to a canonical spec
with `defineRecipe(spec, { shell, slots })` from `@schema-engine/forms-react/primitives`; it requires exactly the slots the spec declares.
Built-in specs are exported from `@schema-engine/forms/recipes/built-in`. The package root
`@schema-engine/forms` does not re-export them.

`createFormEngine()` does not bind default recipes. That is not the same
as omitting `FormRenderer`, which still lives in this package.

## Form hooks

`@schema-engine/forms-react/adapters` exports `useFormContext`, `useFormField`, `useWatchField`,
`useWatchForm`, and `useFieldArray`. They are adapter-neutral and can be used
inside recipe blocks as well as ordinary form elements.

`useFieldArray` returns `fields` and the mutation methods `append`, `prepend`,
`insert`, `swap`, `move`, `update`, `replace`, and `remove`.
