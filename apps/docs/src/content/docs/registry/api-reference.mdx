# API Reference

Complete API documentation for `@schema-engine/registry`.

## createRegistry

```typescript
function createRegistry<TRegistration extends BaseRegistration>(
	kind: string,
	registrations: readonly TRegistration[],
): ReadOnlyRegistry<TRegistration>;
```

Builds a frozen, read-only registry. A later registration with the same `$type` replaces an earlier one without a warning and keeps its first position. Throws `<kind> '<$type>' schema must implement Standard Schema (~standard.validate).` when a winning registration's schema is not a Standard Schema; an overridden registration is not checked. The registry stores a frozen shallow copy of each winner and leaves the objects you passed untouched.

### ReadOnlyRegistry

| Member     | Returns                      | Description                              |
| ---------- | ---------------------------- | ---------------------------------------- |
| `kind`     | `string`                     | The label passed to `createRegistry`     |
| `size`     | `number`                     | Count of distinct `$type` keys           |
| `get(key)` | `TRegistration \| undefined` | Gets a registration by `$type`           |
| `has(key)` | `boolean`                    | Checks if the key exists                 |
| `all()`    | `readonly TRegistration[]`   | Frozen array in first-registration order |
| `keys()`   | `readonly string[]`          | Frozen array of keys in the same order   |

## assertStandardSchema

```typescript
function assertStandardSchema(schema: unknown, context?: string): StandardSchemaV1;
```

Throws `<context> must implement Standard Schema (~standard.validate).` unless `schema` has a `~standard.validate` function.

## BaseRegistry

Abstract, mutable class for plugin systems that register at runtime. Prefer `createRegistry` otherwise.

```typescript
abstract class BaseRegistry<TKey extends string, TValue extends BaseRegistration> {
	protected items: Map<TKey, TValue>;

	abstract get registryName(): string;
	protected getItemKey(item: TValue): TKey;
	protected getItemName(item: TValue): string;

	register(item: TValue): void;
	has(key: TKey): boolean;
	get(key: TKey): TValue | undefined;
	getAll(): TValue[];
	getAllKeys(): TKey[];
	get size(): number;
	clear(): void;
}
```

### Methods

| Method           | Returns               | Description                                  |
| ---------------- | --------------------- | -------------------------------------------- |
| `register(item)` | `void`                | Registers an item. Logs warning on override. |
| `has(key)`       | `boolean`             | Checks if key exists                         |
| `get(key)`       | `TValue \| undefined` | Gets item by key                             |
| `getAll()`       | `TValue[]`            | Returns all items                            |
| `getAllKeys()`   | `TKey[]`              | Returns all keys                             |
| `size`           | `number`              | Count of items                               |
| `clear()`        | `void`                | Removes all items                            |

### Protected Methods

| Method              | Description                                    |
| ------------------- | ---------------------------------------------- |
| `getItemKey(item)`  | Extracts key from item (uses `$type`)          |
| `getItemName(item)` | Extracts name from item (uses `metadata.name`) |

## Types

### BaseRegistration

```typescript
import type { StandardSchemaV1 } from '@standard-schema/spec';

interface BaseRegistration<TConfig = unknown, TMeta extends RegistrationMetadata = ComponentMetadata> {
	$type: string;
	schema: StandardSchemaV1;
	metadata: TMeta;
}
```

Zod Mini, Zod, Valibot, and Effect Schema values implement Standard Schema and remain valid `schema` values.

### RegistrationMetadata

```typescript
interface RegistrationMetadata {
	name: string;
	description?: string;
}
```

### ComponentRegistration

```typescript
interface ComponentRegistration<
	TType extends string = string,
	TConfig = unknown,
	TProps = unknown,
	TMeta extends ComponentMetadata = ComponentMetadata,
> extends BaseRegistration<TConfig, TMeta> {
	/** Framework-agnostic render function */
	render: (props: TProps) => unknown;
	/** Type identifier - enforced to match registry key */
	$type: TType;
}
```

### ComponentMetadata

```typescript
interface ComponentMetadata extends RegistrationMetadata {
	icon?: string;
	tags?: string[];
	version?: string;
}
```

### Brand

Utility type for compile-time type discrimination (erased at runtime):

```typescript
type Brand<T, TBrand> = T & { readonly [__brand]?: TBrand };
```
