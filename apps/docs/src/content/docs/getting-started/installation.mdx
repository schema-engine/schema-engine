# Installation

## Package Installation

Schema Engine is a monorepo with multiple packages. Install only what you need:

```bash
# Core packages
bun add @schema-engine/forms @schema-engine/forms-react @schema-engine/layout react react-dom zod

# React Hook Form adapter (@schema-engine/forms-react/adapters/react-hook-form),
# used by the Quick Start and the Forms React guides
bun add react-hook-form

# Optional: standalone actions package
bun add @schema-engine/actions
```

### Package Overview

| Package                        | Description                              |
| ------------------------------ | ---------------------------------------- |
| `@schema-engine/forms`         | Core form engine (framework-agnostic)    |
| `@schema-engine/forms-react`   | React components and hooks               |
| `@schema-engine/forms-radiant` | Radiant (Ecopages) renderer              |
| `@schema-engine/actions`       | Domain-agnostic action system            |
| `@schema-engine/layout`        | Grid and appearance theme (neutral)      |
| `@schema-engine/registry`      | Registries, and YAML documents (`/yaml`) |

## Development Setup

To contribute or explore the source code:

### Prerequisites

- **pnpm** - The workspace uses pnpm
- **Node.js** 24 or newer
- **Git** for cloning the repository

### Clone and Setup

```bash
# Clone the repository
git clone git@github.com:andeeplus/schema-engine.git
cd schema-engine

# Install dependencies
pnpm install

# Start the documentation site
pnpm dev:docs
```

### Development Scripts

```bash
# Start the documentation site
pnpm dev:docs

# Build all packages, then type-check them and the docs
pnpm build:lib

# Run the unit and browser tests
pnpm test:all

# Lint
pnpm lint
```

### Verification

To verify that the installation was successful, check the version of the installed packages:

```bash
pnpm list --depth 0 | grep schema-engine
```

You should see `@schema-engine/forms` and `@schema-engine/forms-react` listed with their versions.

## TypeScript Configuration

Schema Engine is built with TypeScript. Recommended `tsconfig.json`:

```json
{
	"compilerOptions": {
		"strict": true,
		"esModuleInterop": true,
		"skipLibCheck": true,
		"moduleResolution": "bundler",
		"jsx": "react-jsx"
	}
}
```

## Peer Dependencies

The packages require the following peer dependencies:

- `zod` >= 4.0.17 when using first-party Zod Mini schemas
- `react` and `react-dom` >= 19 (for forms-react)
- `react-hook-form` >= 7.60 (optional; required when using the React Hook Form adapter)
