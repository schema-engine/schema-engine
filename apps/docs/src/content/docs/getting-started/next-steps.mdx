# Next Steps

You now have a working form, an engine instance, and a renderer wired up.
Here is where to go next.

## Pick a path

- **Need richer forms?** Read the [Components](/docs/forms-react/components) page
  to see every element registration that ships with `forms-react`, then
  [Layouts](/docs/forms-react/layouts) for the visual structure.
- **Need validation beyond rules?** Read [Custom Validations](/docs/forms/validation-custom)
  to author your own rules and register them with the engine.
- **Need form submission, analytics, or auto-save?** Read
  [How Actions Work](/docs/actions/how-it-works) and
  [Available Plugins](/docs/actions/available-plugins).
- **Need multi-step flows?** Read [Steppers](/docs/forms-react/steppers) and
  study the [Registration Flow](/docs/examples/registration-flow) example.

## Ship something

Take one of the [Examples](/docs/examples) and adapt the config to your
real form. The examples cover the most common patterns: basic, contact,
registration, survey, and sequential-action workflows.

## Read the API

When you need an exact signature, the [API Reference](/docs/forms-react/api-reference)
for `forms-react` and the [API Reference](/docs/actions/api-reference) for
`actions` are the source of truth.

## Get help

- Open an issue on the [GitHub repository](https://github.com/andeeplus/schema-engine).
- Read the [Registry API Reference](/docs/registry/api-reference) if you are
  extending the framework with your own plugins.
