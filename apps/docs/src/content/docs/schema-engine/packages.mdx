# Packages

Schema Engine is a set of packages that build on each other. Install the ones the job needs and no more.

## Requirements

- **Node.js** `^24.22.0 || >=26.0.0` is what the packages are built and tested with. They declare no Node engine of their own. Their runtime requirements are the peer dependencies below.
- **pnpm** 10. The commands here use it, and `npm` and `yarn` take the same package names.
- **TypeScript** `^5.4`. `@schema-engine/registry`, `@schema-engine/actions` and `@schema-engine/layout` accept `^5`.
- **A Standard Schema validator**, such as Zod, Valibot or Effect Schema. Registrations take any of them. The examples use `zod/mini`, and `zod` `^4.5.0` is a peer of the forms and layout packages.

## What each package does

| Package                        | What it is for                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `@schema-engine/registry`      | Registries of registrations keyed by `$type`, and YAML documents with line-accurate errors (`/yaml`) |
| `@schema-engine/actions`       | Registered actions, and a dispatcher that runs them in sequence and in parallel groups               |
| `@schema-engine/layout`        | Domain-neutral grid, named appearance, themes and the recipe protocol                                |
| `@schema-engine/forms`         | The forms domain: the engine, fields, validation, constraints, steps, form state and submission      |
| `@schema-engine/forms-react`   | The React renderer for forms: `FormRenderer`, hooks and the field primitives                         |
| `@schema-engine/forms-radiant` | The Radiant renderer for forms: custom elements, form controls and the registrations it ships        |

`@schema-engine/actions` depends on the registry. `@schema-engine/forms` depends on the registry, actions and layout, so installing it brings them in.

## Install for the job

| Job                          | Install                                                                                                                                                       | Then read                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| A registry only              | `pnpm add @schema-engine/registry zod`                                                                                                                        | [Registry](/docs/registry/overview)           |
| Actions only                 | `pnpm add @schema-engine/actions @schema-engine/registry zod`                                                                                                 | [Actions](/docs/actions/overview)             |
| A React form                 | `pnpm add @schema-engine/forms @schema-engine/forms-react @schema-engine/layout react react-dom zod`                                                          | [Forms React](/docs/forms-react/overview)     |
| A Radiant form               | `pnpm add @schema-engine/forms @schema-engine/forms-radiant @schema-engine/layout @ecopages/radiant-ui @ecopages/radiant @ecopages/jsx @ecopages/signals zod` | [Forms Radiant](/docs/forms-radiant/overview) |
| A layout theme without forms | `pnpm add @schema-engine/layout zod`                                                                                                                          | [Layout](/docs/layout/overview)               |

Zod is only needed to author schemas with `zod/mini`. A registration written against another Standard Schema validator installs that validator instead.

## Peer dependencies

The ranges are the ones in the package manifests. A peer on another Schema Engine package means the same release of it.

| Package                        | Peer dependencies                                                                                                                                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@schema-engine/registry`      | `typescript` `^5`; `yaml` `^2.8.0`, optional, needed only for `@schema-engine/registry/yaml`                                                                                                                       |
| `@schema-engine/actions`       | `typescript` `^5`                                                                                                                                                                                                  |
| `@schema-engine/layout`        | `typescript` `^5`, `zod` `^4.5.0`                                                                                                                                                                                  |
| `@schema-engine/forms`         | `typescript` `^5.4`, `zod` `^4.5.0`                                                                                                                                                                                |
| `@schema-engine/forms-react`   | `@schema-engine/forms`, `@schema-engine/layout`, `react` `^19`, `react-dom` `^19`, `typescript` `^5.4`, `zod` `^4.5.0`                                                                                             |
| `@schema-engine/forms-radiant` | `@schema-engine/forms`, `@schema-engine/layout`, `@ecopages/jsx` `>=0.12.0`, `@ecopages/radiant` `>=0.12.0`, `@ecopages/signals` `>=0.12.0`, `@ecopages/radiant-ui` `>=0.6.1`, `typescript` `^5.4`, `zod` `^4.5.0` |

## TypeScript configuration

Every package needs strict mode and bundler module resolution:

```json
{
	"compilerOptions": {
		"strict": true,
		"moduleResolution": "bundler",
		"skipLibCheck": true
	}
}
```

The registry, actions and layout need nothing else. A renderer sets the JSX transform:

| Renderer | Extra `compilerOptions`                                       |
| -------- | ------------------------------------------------------------- |
| React    | `"jsx": "react-jsx"`                                          |
| Radiant  | `"jsx": "react-jsx"` and `"jsxImportSource": "@ecopages/jsx"` |

## Verify the install

```bash
pnpm list --depth 0 | grep schema-engine
```

The output lists each Schema Engine package you installed, with its version.

All Schema Engine packages are released together on one version number. Install the same version of every one you use: two versions of `@schema-engine/registry` in one app (for example yours and a copy nested under `@schema-engine/layout`) give two incompatible sets of registry types. If the list shows different versions, upgrade them together, or run `pnpm why @schema-engine/registry` to find the copy that differs.
