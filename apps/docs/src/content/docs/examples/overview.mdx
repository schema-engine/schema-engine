# Examples

An example is one use case, written as files you can copy into an app and run. Each example page shows every file word for word, and a test runs the same files, so a snippet cannot drift from the code that works.

## What an example holds

- **The files.** Each is a module that imports only packages and its sibling files (`./config`). It imports nothing else, so it runs where you paste it.
- **The page.** It states the install line, then shows every file under its name. An example that renders UI has a live demo, and a forms example shows its React and Radiant files in tabs side by side.
- **The test.** It runs the files, including the failure paths, in a unit or browser test. An example that is not tested, or whose page differs from its files, fails a test.

## Copy an example

1. Run the install line at the top of the example's page.
2. Create one folder and copy every file of the page into it under the name above the code. The files import each other as `./name`, so they keep working side by side.
3. Run the entry the page names, or render the component it exports.

The layout examples below style a form. Each is a form config with the CSS or the theme it needs, rendered live, and they share the two install lines of the forms examples. Set your app up as the getting-started page of your renderer says ([Forms Radiant](/docs/forms-radiant/getting-started) or [Forms React](/docs/forms-react/getting-started)), copy the files into one folder, and render the config:

```tsx
import { FormRenderer, createRadiantFormEngine, schemaFormRegistrations } from '@schema-engine/forms-radiant';
import type { FormConfig } from '@schema-engine/forms';

const engine = createRadiantFormEngine({ elements: schemaFormRegistrations });

export function Layouted({ config }: { config: FormConfig }) {
	return <FormRenderer engine={engine} config={config} onSubmit={(data) => console.log(data)} />;
}
```

In React, create the engine with the widgets you wrote or, optionally, with the fields you copied from the shadcn registry, as [Forms React](/docs/forms-react/getting-started) shows, and render `FormRenderer` with the same `config`. Every CSS file is scoped by the class its config puts on the form with `className`, so it applies only once pasted with that config. The demos use Radiant-styled widgets, not the shadcn registry components, so fallbacks such as the card's maximum width and shadow differ from a registry install.
