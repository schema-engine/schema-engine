# Contact Form

This example combines shared element configuration with conditional behavior
and a responsive form grid.

## Configuration pattern

```ts
const formConfig: FormConfig = {
	id: 'contact',
	title: 'Contact us',
	steps: [
		{
			id: 'details',
			title: 'Contact details',
			elements: [
				{
					$type: 'select',
					id: 'subject',
					name: 'subject',
					label: 'Subject',
					options: [
						{ value: 'general', label: 'General question' },
						{ value: 'support', label: 'Technical support' },
					],
					constraints: [],
				},
				{
					$type: 'input',
					id: 'ticket',
					name: 'ticket',
					label: 'Support ticket number',
					constraints: [
						{ field: 'subject', operator: 'equals', value: 'support', action: 'show' },
					],
				},
				{
					$type: 'textarea',
					id: 'message',
					name: 'message',
					label: 'Message',
					grid: { column: '1 / -1' },
				},
			],
		},
	],
	grid: {
		columns: 2,
		gap: '1rem',
		responsive: { default: { columns: 1 }, md: { columns: 2 } },
	},
	view: { $type: 'card' },
};
```

`constraints` are direct objects on the element. The field's visibility is
derived from the current form value; it is not a separate layout or step
configuration.

See [constraint logic](/docs/forms-react/advanced), [validation](/docs/forms/validation),
and [components](/docs/forms-react/components) for the underlying contracts.
