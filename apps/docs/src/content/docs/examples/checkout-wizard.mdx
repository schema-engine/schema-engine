# A card wizard with per-step areas

A step's `grid` replaces the form's grid for that step, so each step of a wizard draws its own layout and claims every area in it. The names are ASCII CSS identifiers, and each field claims one with `grid.area`.

## Install

For React:

```bash
pnpm add @schema-engine/forms @schema-engine/forms-react @schema-engine/layout react react-dom zod
```

For Radiant:

```bash
pnpm add @schema-engine/forms @schema-engine/forms-radiant @schema-engine/layout @ecopages/radiant-ui @ecopages/radiant @ecopages/jsx @ecopages/signals zod
```

Set your app up as the getting-started page of your renderer says ([Forms Radiant](/docs/forms-radiant/getting-started) or [Forms React](/docs/forms-react/getting-started)), then copy the files below into one folder.

## The config

The config is data: it names the layout it wants, and the CSS and the theme below decide how it looks.

```ts title="config.ts"
import type { FormConfig } from '@schema-engine/forms';

/** Multi-step card wizard whose steps each draw their own layout. */
export const checkoutWizard: FormConfig = {
	id: 'checkout-wizard',
	title: 'Checkout',
	className: 'checkout-wizard',
	view: { $type: 'card-wizard' },
	steps: [
		{
			id: 'address',
			title: 'Address',
			grid: { areas: ['street street', 'city zip'] },
			elements: [
				{ $type: 'input', id: 'street', name: 'street', label: 'Street', grid: { area: 'street' } },
				{ $type: 'input', id: 'city', name: 'city', label: 'City', grid: { area: 'city' } },
				{ $type: 'input', id: 'zip', name: 'zip', label: 'ZIP code', grid: { area: 'zip' } },
			],
		},
		{
			id: 'payment',
			title: 'Payment',
			grid: { areas: ['card card', 'expiry cvc'] },
			elements: [
				{ $type: 'input', id: 'card', name: 'card', label: 'Card number', grid: { area: 'card' } },
				{ $type: 'input', id: 'expiry', name: 'expiry', label: 'Expiry', grid: { area: 'expiry' } },
				{ $type: 'input', id: 'cvc', name: 'cvc', label: 'CVC', grid: { area: 'cvc' } },
			],
		},
	],
};
```

## The CSS

```css title="checkout-wizard.css"
.checkout-wizard {

```

## What the tests check

The test checks that the config is valid in a Radiant engine, that every field claims an area its own step draws, and that the CSS styles the class the config puts on the form and no other.
