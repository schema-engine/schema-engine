# A complete theme file

This file themes every form that carries `className: 'acme'`: rhythm, the size hooks, the colour roles and the literal tokens of two axis values. The form picks `size: comfortable` and `surface: outlined`, so it exercises all four groups. Give each form that should use it `className: 'acme'`. The gap tokens, colour roles and size hooks also work from `:root`. The rules in the last two blocks target the elements that carry the picks.

## Install

For React:

```bash
pnpm add @schema-engine/forms @schema-engine/forms-react @schema-engine/layout react react-dom zod
```

For Radiant:

```bash
pnpm add @schema-engine/forms @schema-engine/forms-radiant @schema-engine/layout @ecopages/radiant-ui @ecopages/radiant @ecopages/jsx @ecopages/signals zod
```

Set your app up as the getting-started page of your renderer says ([Forms Radiant](/docs/forms-radiant/getting-started) or [Forms React](/docs/forms-react/getting-started)), then copy the files below into one folder.

## The config

The config is data: it names the layout it wants, and the CSS and the theme below decide how it looks.

```ts title="config.ts"
import type { FormConfig } from '@schema-engine/forms';

/** A form that picks values of two axes, under a host theme file. */
export const acmeForm: FormConfig = {
	id: 'acme-theme',
	title: 'Create an account',
	className: 'acme',
	view: { $type: 'card', shell: { appearance: { size: 'comfortable', surface: 'outlined' } } },
	steps: [
		{
			id: 'account',
			title: 'Account',
			elements: [
				{ $type: 'input', id: 'name', name: 'name', label: 'Name', grid: { width: 'half' } },
				{ $type: 'input', id: 'company', name: 'company', label: 'Company', grid: { width: 'half' } },
				{ $type: 'input', id: 'email', name: 'email', label: 'Email', inputType: 'email' },
			],
		},
	],
};
```

## The CSS

```css title="acme-theme.css"
/*
 * acme-theme.css: one theme for every form that carries `className: 'acme'`.
 * The gap tokens, the size hooks and the colour roles also work from `:root` or any ancestor, in both
 * renderers; the nearest setting wins.
 */
.acme {
	/* 1. Rhythm: the gap tokens every grid reads. */
	--se-grid-gap-compact: 0.5rem;
	--se-grid-gap-default: 1rem;
	--se-grid-gap-loose: 1.75rem;
	--se-grid-gap-wide: 2.5rem;

	/* 2. The hooks the built-in size axis reads. */
	--se-space-compact: 0.75rem;
	--se-space-comfortable: 2.25rem;
	--se-control-height-compact: 2rem;
	--se-control-height-comfortable: 2.75rem;

	/* 3. Colour roles of your design system: Radiant UI and shadcn components read them. */
	--primary: #4f46e5;
	--on-primary: #ffffff;
}

/* 4. Literal tokens of an axis value: set them on the element that carries the pick. */
.acme [data-se-size='comfortable'] {
	--se-measure: 36rem;
}

.acme [data-se-surface='outlined'] {
	--se-border-width: 2px;
}
```

## What the tests check

The test checks that the config is valid in a Radiant engine, that the axis values it picks exist and the hooks the CSS sets are the ones those values read, and that every rule is scoped by the class of the config.
