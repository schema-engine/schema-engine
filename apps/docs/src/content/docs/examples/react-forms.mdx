# React Forms

Each form on this page is a live `@schema-engine/forms-react` form. The code block under it is serialized from the same object the form renders, so the two cannot drift. Submit handling is local: a valid submit shows the submitted values under the form and nothing reaches a server.

Most examples use the docs' Radiant-styled demo kit, so they share their configuration with the Radiant examples ([Basic form](/docs/examples/basic-form), [Contact form](/docs/examples/contact-form), [Registration flow](/docs/examples/registration-flow), [Survey form](/docs/examples/survey-form), [Sequential actions](/docs/examples/sequential-actions)). The last section uses source copied from the shadcn registry.

## Copied shadcn source

This form renders with the registry's `input` field and `card` recipe, not with the demo kit. The docs app copies the same files, to the same target paths and with the same import rewrites that `shadcn add` applies, into `src/generated/shadcn` before dev and build; it does not run the CLI. The files are read from `registry.json`, the shadcn `input`, `label` and `button` come from this repository's own copies, and components are written as `.react.tsx` for the docs' React integration.

<ShadcnFormDemoEmbed config={shadcnContactFormConfig} />

<FormConfigCode config={shadcnContactFormConfig} rootName="shadcnContactFormConfig" />

The engine registers the copied field and recipe like any consumer's would:

```typescript
import { createFormEngine } from '@schema-engine/forms';
import { InputElementRegistration } from '@/components/schema-engine/forms/inputs/form-input.registration';
import { CardRecipe } from '@/components/schema-engine/forms/recipes/registrations/card';

const engine = createFormEngine({
	elements: [InputElementRegistration],
	recipes: [CardRecipe],
});
```

The provider, the renderer and the copied field's hooks all import `@schema-engine/forms-react` from the one package, so they share one React context. A bundle that ends up with two copies of the package splits the context, and the field then throws a missing-provider error; keep one copy in your app. See [Registries](/docs/registry/registries) and [View recipes](/docs/forms-react/layouts#default-registry-recipes) for installing the source in your own app.
