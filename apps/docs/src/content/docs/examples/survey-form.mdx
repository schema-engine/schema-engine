# Survey Form

This survey demonstrates a wizard recipe, choice elements, and a conditional
follow-up question.

## Configuration pattern

```ts
const formConfig: FormConfig = {
	id: 'customer-survey',
	title: 'Customer satisfaction',
	view: { $type: 'wizard' },
	steps: [
		{
			id: 'rating',
			title: 'Your experience',
			elements: [
				{
					$type: 'select',
					id: 'satisfaction',
					name: 'satisfaction',
					label: 'How satisfied are you?',
					options: [
						{ value: '5', label: 'Very satisfied' },
						{ value: '3', label: 'Neutral' },
						{ value: '1', label: 'Very dissatisfied' },
					],
				},
			],
		},
		{
			id: 'feedback',
			title: 'Feedback',
			elements: [
				{
					$type: 'textarea',
					id: 'improvements',
					name: 'improvements',
					label: 'What could we improve?',
					constraints: [
						{ field: 'satisfaction', operator: 'equals', value: '1', action: 'show' },
					],
				},
			],
		},
	],
};
```

Constraints are direct element properties with one effect per object. Use
multiple elements when a follow-up should appear for several independent
answers, or register a custom element when the interaction needs richer
behavior.

See [constraint logic](/docs/forms-react/advanced), [validation](/docs/forms/validation),
and [View recipes](/docs/forms-react/layouts).
