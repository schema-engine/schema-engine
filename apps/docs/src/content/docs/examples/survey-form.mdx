# Survey Form

These previews use Radiant because the docs app is Ecopages + Radiant UI.

This survey demonstrates a wizard recipe, choice elements, and a conditional
follow-up question.

## Configuration pattern

<FormConfigCode config={surveyDemoConfig} />

Constraints are direct element properties with one effect per object. Use
multiple elements when a follow-up should appear for several independent
answers, or register a custom element when the interaction needs richer
behavior.

The [React Forms](/docs/examples/react-forms#multi-step-wizard) page runs a wizard like this one in React.

See [constraints](/docs/forms/constraints), [validation](/docs/forms/validation),
and [View recipes](/docs/forms-react/layouts).
