# Sequential Actions

These previews use Radiant because the docs app is Ecopages + Radiant UI.

Actions are registered capabilities that run in response to lifecycle
triggers. The form configuration determines the order in which action entries
are evaluated. Single-step recipes such as `card` render a submit control in
the actions slot; that control starts the submit lifecycle that runs the
plugins below.

## Configuration pattern

<FormConfigCode config={sequentialActionsDemoConfig} />

Register the corresponding action registrations with
`createFormEngine({ actions: [...] })`. Docs previews route `show_notification`
through `notificationPlugin({ onNotification })` and the site-wide
`<RuiToaster position="bottom-end" />`. Use `form_submit_start`,
`form_submit_success`, `form_submit_error`, and `form_submit_complete` for the
submit lifecycle; step navigation uses the `step_*` triggers.

See [Actions](/docs/forms/actions) for the built-in registrations and
[Concepts](/docs/actions/concepts) for execution semantics.
