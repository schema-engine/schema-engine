# Basic Form

These previews use Radiant because the docs app is Ecopages + Radiant UI.

This is the smallest useful JSON form: register elements, describe steps as
data, and choose an optional view recipe at the form level.

## Interactive demo

<FormRendererPreview config={basicContactFormConfig} />

## Configuration

<FormConfigCode config={basicContactFormConfig} />

The renderer validates the configuration against the registrations in the
engine. A form without `view` is also valid; it renders its elements without
recipe-provided chrome.

## Extend it

- Add [validation rules](/docs/forms/validation) to an element.
- Add responsive placement with the form or element `grid` property.
- Add a [view recipe](/docs/forms-react/layouts) when the form needs a shell
  or wizard navigation.
- Add [actions](/docs/forms/actions) for submission and lifecycle behavior.
