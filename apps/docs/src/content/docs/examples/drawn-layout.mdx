# A responsive drawn layout

Five fields, stacked on small screens and drawn from `md` up: `A` spans three columns and two rows, `B` and `C` stack beside it, and `D` and `E` share the last row. `areas` is a record keyed by breakpoint, and it must include `default`. Resize the window to see the layout change.

The rules for areas, and every validation error, are in [Drawn layouts](/docs/layout/grid-and-placement#drawn-layouts-areas).

## Install

For React:

```bash
pnpm add @schema-engine/forms @schema-engine/forms-react @schema-engine/layout react react-dom zod
```

For Radiant:

```bash
pnpm add @schema-engine/forms @schema-engine/forms-radiant @schema-engine/layout @ecopages/radiant-ui @ecopages/radiant @ecopages/jsx @ecopages/signals zod
```

Set your app up as the getting-started page of your renderer says ([Forms Radiant](/docs/forms-radiant/getting-started) or [Forms React](/docs/forms-react/getting-started)), then copy the files below into one folder.

## The config

The config is data: it names the layout it wants, and the CSS and the theme below decide how it looks.

```ts title="config.ts"
import type { FormConfig } from '@schema-engine/forms';

/** The drawn layout of the styling overview: five fields, stacked below `md`. */
export const drawnLayout: FormConfig = {
	id: 'drawn-layout',
	className: 'drawn-layout',
	grid: {
		areas: {
			default: ['a', 'b', 'c', 'd', 'e'],
			md: ['a a a b b b', 'a a a c c c', 'd d e e e e'],
		},
	},
	steps: [
		{
			id: 'fields',
			title: 'Fields',
			elements: [
				{ $type: 'input', id: 'a', name: 'a', label: 'A', grid: { area: 'a' } },
				{ $type: 'input', id: 'b', name: 'b', label: 'B', grid: { area: 'b' } },
				{ $type: 'input', id: 'c', name: 'c', label: 'C', grid: { area: 'c' } },
				{ $type: 'input', id: 'd', name: 'd', label: 'D', grid: { area: 'd' } },
				{ $type: 'input', id: 'e', name: 'e', label: 'E', grid: { area: 'e' } },
			],
		},
	],
};
```

## The CSS

```css title="drawn-layout.css"
/* Areas and widths come from the config; the only CSS is the rhythm between the cells. */
.drawn-layout {
	--se-grid-gap-default: 0.75rem;
}
```

## What the tests check

The test checks that the config is valid in a Radiant engine, that it draws a template for `default` and for `md` and that each template draws every field, and that the CSS styles the class the config puts on the form and no other.
