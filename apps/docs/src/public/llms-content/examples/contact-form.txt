# Contact Form

These previews use Radiant because the docs app is Ecopages + Radiant UI.

This example combines shared element configuration with conditional behavior.
Each field sits on its own line. Form-level `title` and `description` feed the
card header together with the step `title` (required on every step).

`constraints` are direct objects on the element. The field's visibility is
derived from the current form value; it is not a separate layout or step
configuration.

The same configuration renders in React: [React Forms](/docs/examples/react-forms#conditional-fields).

See [constraint logic](/docs/forms-react/advanced), [validation](/docs/forms/validation),
and [components](/docs/forms-react/components) for the underlying contracts.
