# How Layout & Styles Work

Form Engine includes a powerful responsive grid system that automatically handles form layout across different screen sizes. Built on CSS Grid with a mobile-first approach, it ensures your forms look great everywhere without manual responsive coding.

## Responsive Grid System

The grid system uses a 12-column layout with five responsive breakpoints:

```typescript
// Responsive breakpoints
const breakpoints = {
  xs: '0px',      // Mobile (default)
  sm: '640px',    // Large mobile
  md: '768px',    // Tablet  
  lg: '1024px',   // Desktop
  xl: '1280px'    // Large desktop
};

// Column system (1-12 columns)
const gridColumns = {
  1: '8.333333%',   // 1/12
  2: '16.666667%',  // 2/12  
  3: '25%',         // 3/12
  4: '33.333333%',  // 4/12
  6: '50%',         // 6/12
  8: '66.666667%',  // 8/12
  12: '100%'        // 12/12 (full width)
};
```

### Automatic Column Calculation
When you don't specify grid positions, Form Engine automatically arranges elements:

```typescript
// These fields will automatically flow in the grid
const autoLayoutFields = [
  { componentId: 'input', id: 'firstName', label: 'First Name' },
  { componentId: 'input', id: 'lastName', label: 'Last Name' },  
  { componentId: 'input', id: 'email', label: 'Email' },
  { componentId: 'textarea', id: 'bio', label: 'Bio' }
];

// Result: firstName and lastName side-by-side on desktop,
// email and bio full-width, all stacked on mobile
```

## Grid Configuration Options

### Form-Level Grid Settings

```typescript
const formConfig = {
  id: 'my-form',
  
  // Grid configuration
  grid: {
    columns: 12,                    // Total columns (1-12)
    gap: {                          // Spacing between fields
      xs: '1rem',                   // Mobile gap
      md: '1.5rem',                 // Desktop gap  
      lg: '2rem'                    // Large screen gap
    },
    padding: {                      // Container padding
      xs: '1rem',
      md: '2rem'
    },
    maxWidth: '800px',              // Maximum form width
    align: 'center'                 // Form alignment
  }
};
```

### Field-Level Grid Positioning

```typescript
const fieldWithGridPosition = {
  componentId: 'input',
  id: 'address',
  label: 'Street Address',
  
  // Responsive grid positioning
  grid: {
    column: {
      xs: 12,        // Full width on mobile
      sm: 8,         // 8/12 columns on large mobile
      md: 6,         // Half width on tablet+
      lg: 4          // Third width on desktop+
    },
    row: {
      xs: 'auto',    // Auto-flow on mobile
      md: 1          // Specific row on desktop
    },
    order: {
      xs: 0,         // Default order on mobile  
      md: -1         // Move up on desktop
    }
  }
};
```

## CSS-in-JS vs External Styles

Form Engine supports multiple styling approaches:

### Built-in Tailwind Classes (Default)

```tsx
// Default field components use Tailwind
const DefaultInput = ({ label, error, field, ...props }) => (
  <div className="mb-6">
    <label className="block text-sm font-medium text-gray-700 mb-2">
      {label}
    </label>
    <input
      className={`
        w-full px-3 py-2 border border-gray-300 rounded-md 
        focus:outline-none focus:ring-2 focus:ring-blue-500 focus:border-transparent
        ${error ? 'border-red-500' : ''}
      `}
      {...field}
      {...props}
    />
    {error && (
      <p className="mt-1 text-sm text-red-600">{error}</p>
    )}
  </div>
);
```

### Custom CSS Classes

```tsx
// Use your own CSS classes
const CustomInput = ({ label, error, field, ...props }) => (
  <div className="form-field">
    <label className="form-label">{label}</label>
    <input 
      className={`form-input ${error ? 'form-input--error' : ''}`}
      {...field}
      {...props}
    />
    {error && <span className="form-error">{error}</span>}
  </div>
);

// Corresponding CSS
`.form-field {
  margin-bottom: 1.5rem;
}

.form-label {
  display: block;
  font-weight: 500;
  margin-bottom: 0.5rem;
  color: var(--text-primary);
}

.form-input {
  width: 100%;
  padding: 0.75rem;
  border: 1px solid var(--border-color);
  border-radius: 0.375rem;
  transition: all 0.2s;
}

.form-input:focus {
  outline: none;
  border-color: var(--primary-color);
  box-shadow: 0 0 0 3px var(--primary-color-alpha);
}

.form-input--error {
  border-color: var(--error-color);
}`
```

### CSS-in-JS with Styled Components

```typescript
import styled from 'styled-components';

const StyledFieldContainer = styled.div\`
  margin-bottom: 1.5rem;
\`;

const StyledLabel = styled.label\`
  display: block;
  font-weight: 500;
  margin-bottom: 0.5rem;
  color: \${props => props.theme.colors.text.primary};
\`;

const StyledInput = styled.input<{ hasError?: boolean }>\`
  width: 100%;
  padding: 0.75rem;
  border: 1px solid \${props => props.hasError 
    ? props.theme.colors.error 
    : props.theme.colors.border};
  border-radius: 0.375rem;
  transition: all 0.2s;
  
  &:focus {
    outline: none;
    border-color: \${props => props.theme.colors.primary};
    box-shadow: 0 0 0 3px \${props => props.theme.colors.primary}20;
  }
\`;

const StyledInput = ({ label, error, field, ...props }) => (
  <StyledFieldContainer>
    <StyledLabel>{label}</StyledLabel>
    <StyledInput hasError={!!error} {...field} {...props} />
    {error && <ErrorMessage>{error}</ErrorMessage>}
  </StyledFieldContainer>
);
```

## Theme System Integration

Form Engine can integrate with popular theme systems:

### Material-UI Integration

```typescript
import { useTheme } from '@mui/material/styles';
import { TextField } from '@mui/material';

const MUIInput = ({ label, error, field, config }) => {
  const theme = useTheme();
  
  return (
    <TextField
      label={label}
      error={!!error}
      helperText={error}
      fullWidth
      margin="normal" 
      variant="outlined"
      {...field}
      sx={{
        '& .MuiOutlinedInput-root': {
          '&:hover fieldset': {
            borderColor: theme.palette.primary.main,
          },
        },
      }}
    />
  );
};

import { defaultFormRegistry } from '@/lib/form-engine';

defaultFormRegistry.register({
  name: 'input',
  component: MUIInput,
  category: 'input',
  description: 'Material-UI input field'
});
```

### Chakra UI Integration

```typescript  
import { FormControl, FormLabel, Input, FormErrorMessage } from '@chakra-ui/react';

const ChakraInput = ({ label, error, field, isRequired }) => (
  <FormControl isInvalid={!!error} isRequired={isRequired}>
    <FormLabel>{label}</FormLabel>
    <Input {...field} />
    <FormErrorMessage>{error}</FormErrorMessage>
  </FormControl>
);

defaultFormRegistry.register({
  name: 'input',
  component: ChakraInput,
  category: 'input',
  description: 'Chakra UI input field'
});
```
