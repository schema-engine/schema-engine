# MDX Test Page

This page tests whether MDX with React hydration is working correctly.

export function Counter() {
    const [count, setCount] = useState(0);

    return (
        <div className="p-4 border border-gray-200 rounded-lg">
            <p className="mb-4">Current count: <strong>{count}</strong></p>
            <Button
                onClick={() => setCount(count + 1)}
                className="mr-2"
            >
                Increment
            </Button>
            <Button
                onClick={() => setCount(count - 1)}
                variant="outline"
            >
                Decrement
            </Button>
        </div>
    );
}

## Interactive Counter

Below is a React component that should be fully interactive after hydration:

<Counter />

If you can click the buttons and see the counter change, then hydration is working properly!
