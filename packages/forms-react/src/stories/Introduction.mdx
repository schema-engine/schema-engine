# @schema-engine/forms-react

Render form configurations from `@schema-engine/forms` with React. Applications
install consumer-owned element registrations and view recipes, then pass an
engine and adapter to `FormEngineProvider`.

Create engines with `createFormEngine` from `@schema-engine/forms`. Import
`FormEngineProvider` and `FormRenderer` from `@schema-engine/forms-react`.
The React Hook Form adapter is available only from
`@schema-engine/forms-react/adapters/react-hook-form`; install `react-hook-form`
when choosing that adapter.

Use `/hooks` for runtime and view hooks, `/adapters` for adapter contracts and
form hooks, and `/primitives` for `FormElement`, `FormElements`, and recipe
contracts. `/contexts` supplies the view provider and context types.

The runtime exposes `se-*` class hooks and grid variables. Registry components
choose their own UI library and styling dependencies.

See the [Getting started guide](https://schema-engine.com/docs/forms-react/getting-started)
for installation and a complete rendering example.
