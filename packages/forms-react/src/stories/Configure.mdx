# @schema-engine/forms-react

The official React implementation of the [JSON Form Engine](https://schema-engine.com). This package provides a type-safe, performant, and flexible way to render complex forms using JSON definitions.

## Key Features

- **Type-Safe Builder**: Full TypeScript inference for form configurations and components.
- **Adapter System**: Built-in React Hook Form adapter, extendable to other libraries.
- **Rich Component Library**: Pre-built, accessible form elements.
- **Flexible Layouts**: Visual organization components like Cards and Split Screens.
- **Lifecycle Actions**: Execute HTTP requests, redirects, and state changes on form events.

## Philosophy

Schema Engine is built on **Configuration over Code**. We believe you should define *what* you want, not *how* to build it. By separating the form definition from the implementation, you gain:

- **Portability**: Store forms in databases, send them over the wire.
- **Consistency**: Enforce design systems and validation rules globally.
- **Flexibility**: Adapt to different frameworks and platforms without rewriting logic.
