# Form shells

View recipes compose **shells** (card, hero, split-screen, stack, sidebar) with slot blocks. CSS for the visual shells lives next to the shell components.

Author forms with `view.$type` (for example `card`, `card-wizard`, `wizard`). Register recipes via `createReactFormComposer()` or `FormComposer.addRecipe()`. Built-in recipe specs live in `@schema-engine/forms/recipes` and are not part of the FormEngine entry.
