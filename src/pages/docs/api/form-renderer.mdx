# FormRenderer API

The `FormRenderer` component is the main entry point for rendering forms with Form Engine. It takes a configuration object and renders a complete form with validation, conditional logic, and actions.

## Import

```typescript
import { FormRenderer } from '@/lib/form-engine';
```

## Basic Usage

```typescript
import { FormRenderer } from '@/lib/form-engine';
import type { FormConfig } from '@/lib/form-engine/types';

const formConfig: FormConfig = {
  id: 'my-form',
  mode: 'free',
  autoGenerateSchema: true,
  steps: [
    {
      id: 'step-1',
      title: 'Basic Information',
      fields: [
        {
          type: 'input',
          inputType: 'text',
          id: 'name',
          name: 'name',
          label: 'Full Name',
          validation: [{ type: 'required', message: 'Name is required' }]
        }
      ]
    }
  ],
  actions: [
    {
      id: 'submit-form',
      type: 'submit',
      description: 'Submit form',
      endpoint: '/api/submit',
      method: 'POST'
    }
  ]
};

export function MyForm() {
  return <FormRenderer config={formConfig} />;
}
```

## Props

### config (required)

**Type:** `FormConfig`

The form configuration object that defines the structure, validation, and behavior of the form.

### className

**Type:** `string`  
**Default:** `undefined`

Additional CSS classes to apply to the form container.

```typescript
<FormRenderer 
  config={formConfig} 
  className="max-w-2xl mx-auto" 
/>
```

### onFormChange

**Type:** `(data: Record<string, any>) => void`  
**Default:** `undefined`

Callback fired when form data changes. Useful for debugging or external state synchronization.

```typescript
<FormRenderer 
  config={formConfig} 
  onFormChange={(data) => console.log('Form data:', data)}
/>
```

### initialData

**Type:** `Record<string, any>`  
**Default:** `{}`

Initial values for the form fields.

```typescript
<FormRenderer 
  config={formConfig} 
  initialData={{ name: 'John Doe', email: 'john@example.com' }}
/>
```

### disabled

**Type:** `boolean`  
**Default:** `false`

Disables all form fields and actions when true.

```typescript
<FormRenderer 
  config={formConfig} 
  disabled={isLoading}
/>
```

### onStepChange

**Type:** `(stepIndex: number, stepId: string) => void`  
**Default:** `undefined`

Callback fired when the active step changes in multi-step forms.

```typescript
<FormRenderer 
  config={formConfig} 
  onStepChange={(index, id) => console.log(\`Step changed to \${index}: \${id}\`)}
/>
```

### onValidationError

**Type:** `(errors: Record<string, string>) => void`  
**Default:** `undefined`

Callback fired when validation errors occur.

```typescript
<FormRenderer 
  config={formConfig} 
  onValidationError={(errors) => {
    console.log('Validation errors:', errors);
    // Handle errors (e.g., analytics, logging)
  }}
/>
```

## Advanced Usage

### With Custom Context

```typescript
import { FormEngineProvider, FormRenderer } from '@/lib/form-engine';

function MyFormWithProvider() {
  return (
    <FormEngineProvider
      config={{
        debugMode: true,
        apiBaseUrl: '/api/v1'
      }}
    >
      <FormRenderer config={formConfig} />
    </FormEngineProvider>
  );
}
```

### With Error Boundary

```typescript
import { ErrorBoundary } from 'react-error-boundary';

function MyFormWithErrorHandling() {
  return (
    <ErrorBoundary fallback={<div>Something went wrong</div>}>
      <FormRenderer config={formConfig} />
    </ErrorBoundary>
  );
}
```

### Controlled vs Uncontrolled

FormRenderer can work in both controlled and uncontrolled modes:

```typescript
// Uncontrolled (default) - Form Engine manages state
<FormRenderer config={formConfig} />

// Controlled - You manage state
const [formData, setFormData] = useState({});

<FormRenderer 
  config={formConfig}
  initialData={formData}
  onFormChange={setFormData}
/>
```

## Methods

Access FormRenderer methods using a ref:

```typescript
import { useRef } from 'react';

function MyForm() {
  const formRef = useRef<FormRendererRef>(null);

  const handleReset = () => {
    formRef.current?.reset();
  };

  const handleSubmit = () => {
    formRef.current?.submit();
  };

  const handleValidate = async () => {
    const isValid = await formRef.current?.validate();
    console.log('Form is valid:', isValid);
  };

  return (
    <div>
      <FormRenderer ref={formRef} config={formConfig} />
      <div className="flex gap-2 mt-4">
        <button onClick={handleReset}>Reset</button>
        <button onClick={handleSubmit}>Submit</button>
        <button onClick={handleValidate}>Validate</button>
      </div>
    </div>
  );
}
```

### Available Methods

- **`reset()`** - Reset form to initial values
- **`submit()`** - Trigger form submission
- **`validate()`** - Validate form and return boolean
- **`getValues()`** - Get current form values
- **`setValues(data)`** - Set form values programmatically
- **`clearErrors()`** - Clear all validation errors

## Events

FormRenderer emits various events during its lifecycle:

### onMount

Fired when the form is mounted and ready.

### onSubmitStart

Fired when form submission begins.

### onSubmitSuccess

Fired when form submission completes successfully.

### onSubmitError

Fired when form submission fails.

### onFieldChange

Fired when any field value changes.

### onStepComplete

Fired when a step is completed in multi-step forms.

## Performance Considerations

### Memoization

FormRenderer is optimized for performance but you can help by memoizing the config:

```typescript
import { useMemo } from 'react';

function MyForm() {
  const config = useMemo(() => ({
    id: 'my-form',
    // ... rest of config
  }), []);

  return <FormRenderer config={config} />;
}
```

### Large Forms

For forms with many fields, consider:

- Using virtualization for very long forms
- Splitting into multiple steps
- Lazy loading field components
- Debouncing validation

## Error Handling

FormRenderer provides comprehensive error handling:

```typescript
<FormRenderer 
  config={formConfig}
  onValidationError={(errors) => {
    // Handle validation errors
    Object.entries(errors).forEach(([field, message]) => {
      console.error(\`Field \${field}: \${message}\`);
    });
  }}
  onSubmitError={(error) => {
    // Handle submission errors
    console.error('Submission failed:', error);
  }}
/>
```

## TypeScript Support

FormRenderer provides full TypeScript support with proper type inference:

```typescript
import type { FormConfig, FormRendererProps } from '@/lib/form-engine/types';

// Config is fully typed
const config: FormConfig = {
  // TypeScript will validate this structure
};

// Props are fully typed
const props: FormRendererProps = {
  config,
  className: 'my-form',
  // TypeScript will validate all props
};
```
