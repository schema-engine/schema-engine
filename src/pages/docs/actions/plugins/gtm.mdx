# GTM Plugin

The GTM (Google Tag Manager) plugin provides comprehensive analytics tracking for form interactions. It automatically sends events to Google Tag Manager for form submissions, field interactions, validation errors, and custom user actions.

## Basic Usage

```typescript
import { registerAction } from "@/lib/form-engine/actions/action-registry";
import { gtmPlugin } from "@/lib/form-engine/actions/plugins";

// Register with default configuration
registerAction(gtmPlugin());
```

## Action Configuration

```typescript
{
  id: "track-form-events",
  type: "gtm_track",
  eventName: "form_submit", // Required: GTM event name
  eventAction: "submit", // Optional: event action
  eventCategory: "form", // Optional: event category
  eventLabel: "contact-form", // Optional: event label
  customParameters: { // Optional: additional GTM parameters
    form_id: "contact-form",
    form_type: "lead_generation",
    page_section: "hero"
  },
  triggers: ["submit_success"] // Optional: when to send event
}
```

### Configuration Options

| Option | Type | Required | Default | Description |
|--------|------|----------|---------|-------------|
| `eventName` | `string` | Yes | - | GTM event name (e.g., "form_submit") |
| `eventAction` | `string` | No | `"interaction"` | What action was performed |
| `eventCategory` | `string` | No | `"form"` | Event category for grouping |
| `eventLabel` | `string` | No | - | Additional label for the event |
| `customParameters` | `object` | No | `{}` | Additional parameters to send |
| `includeFormData` | `boolean` | No | `false` | Include form field values (be mindful of PII) |
| `dataLayerName` | `string` | No | `"dataLayer"` | Custom data layer name |

## Plugin Customization

```typescript
registerAction(gtmPlugin({
  // Custom data layer name
  dataLayerName: 'customDataLayer',
  
  // Global parameters added to all events
  globalParameters: {
    app_version: '1.2.3',
    environment: 'production',
    user_type: 'authenticated'
  },
  
  // Data transformation hook
  onBeforeTrack: (eventData, context) => {
    console.log('Sending GTM event:', eventData);
    
    // Add dynamic parameters
    return {
      ...eventData,
      timestamp: Date.now(),
      session_id: getSessionId(),
      user_id: getCurrentUserId(),
      form_completion_time: calculateCompletionTime(context)
    };
  },
  
  // Success callback
  onAfterTrack: (eventData, context) => {
    console.log('GTM event sent successfully');
    
    // Update internal analytics
    internalAnalytics.track('gtm_event_sent', {
      event_name: eventData.event,
      form_id: context.formId
    });
  },
  
  // Error handling
  onError: (error, eventData, context) => {
    console.error('GTM tracking error:', error);
    
    // Fallback tracking
    fallbackAnalytics.track(eventData);
  }
}));
```

### Customization Options

| Option | Type | Description |
|--------|------|-------------|
| `dataLayerName` | `string` | Custom data layer variable name |
| `globalParameters` | `object` | Parameters added to all events |
| `onBeforeTrack` | `(data: any, context: ActionExecutionContext) => any` | Transform data before sending |
| `onAfterTrack` | `(data: any, context: ActionExecutionContext) => void` | Called after successful tracking |
| `onError` | `(error: Error, data: any, context: ActionExecutionContext) => void` | Error handling callback |

## Default Triggers

The GTM plugin responds to these triggers by default:
- `form_submit` - When form is submitted
- `field_change` - When field values change (if configured)

## Advanced Tracking Patterns

### Custom Event with Form Data

```typescript
registerAction(gtmPlugin({
  onBeforeTrack: (eventData, context) => {
    // Add form completion metrics
    const formState = context.getFormState();
    const startTime = context.getStartTime();
    
    return {
      ...eventData,
      form_completion_time: Date.now() - startTime,
      fields_filled: Object.values(formState).filter(v => v).length,
      form_completion_percentage: calculateCompletionPercentage(formState),
      user_agent: navigator.userAgent,
      viewport_size: `${window.innerWidth}x${window.innerHeight}`
    };
  }
}));

const actions = [

      form_id: "registration-form",

      ab_test_variant: "variant-b"

  }
];
```

## Privacy and Compliance

### GDPR-Compliant Tracking

```typescript
registerAction(gtmPlugin({
  onBeforeTrack: (eventData, context) => {
    // Check consent
    const hasAnalyticsConsent = checkGDPRConsent('analytics');
    if (!hasAnalyticsConsent) {
      return null; // Skip tracking if no consent
    }
    
    // Remove PII
    const sanitizedData = { ...eventData };
    delete sanitizedData.email;
    delete sanitizedData.phone;
    delete sanitizedData.name;
    
    return sanitizedData;
  }
}));

const actions = [
  {
    id: "gdpr-compliant-tracking",
    type: "gtm_track",
    eventName: "form_submit",
    includeFormData: false,
    customParameters: {
      consent_given: "{{ gdprConsent.analytics }}",
      consent_timestamp: "{{ gdprConsent.timestamp }}"
    },
    triggers: ["submit_success"]
  }
];
```

### Anonymized User Tracking

```typescript
registerAction(gtmPlugin({
  globalParameters: {

  onBeforeTrack: (eventData, context) => {
    // Remove or hash any identifying information

      ...eventData,

  }

```
