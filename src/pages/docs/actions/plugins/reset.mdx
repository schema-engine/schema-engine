# Reset Plugin

The Reset plugin clears form data and returns the form to its initial state. It provides flexible reset options including clearing values, validation states, and specific field groups.

## Basic Usage

```typescript
import { registerAction } from "@/lib/form-engine/actions/action-registry";
import { resetPlugin } from "@/lib/form-engine/actions/plugins";

// Register with default configuration
registerAction(resetPlugin());
```

## Action Configuration

```typescript
{
  id: "clear-form",
  type: "reset_form",
  resetType: "all", // Required: all|values|validation|specific
  confirmReset: true, // Optional: show confirmation dialog
  confirmMessage: "Are you sure you want to clear all data?", // Optional: custom confirmation message
  targetFields: ["email", "message"], // Optional: specific fields to reset (when resetType: "specific")
  triggers: ["reset_button_click"] // Optional: when to trigger reset
}
```

### Configuration Options

| Option | Type | Required | Default | Description |
|--------|------|----------|---------|-------------|
| `resetType` | `"all" \| "values" \| "validation" \| "specific"` | Yes | `"all"` | What to reset |
| `confirmReset` | `boolean` | No | `false` | Show confirmation dialog |
| `confirmMessage` | `string` | No | `"Are you sure you want to reset the form?"` | Confirmation dialog text |
| `targetFields` | `string[]` | No | `[]` | Fields to reset (when `resetType: "specific"`) |
| `preserveDefaults` | `boolean` | No | `false` | Keep default values when resetting |

### Reset Types

| Type | Description |
|------|-------------|
| `all` | Reset all form data, validation states, and UI state |
| `values` | Reset only field values to defaults/empty |
| `validation` | Clear only validation errors and touched states |
| `specific` | Reset only specified fields in `targetFields` |

## Plugin Customization

```typescript
registerAction(resetPlugin({
  // Custom confirmation dialog
  onConfirm: async (message, context) => {
    return await customDialog.show({
      title: 'Reset Form',
      message,
      buttons: ['Cancel', 'Reset'],
      variant: 'warning'
    });
  },
  
  // Before reset hook
  onBeforeReset: (config, context) => {
    console.log('About to reset:', config.resetType);
    
    // Save current state for undo functionality
    const currentState = context.getFormState();
    localStorage.setItem(`form-backup-${context.formId}`, JSON.stringify(currentState));
  },
  
  // After reset hook
  onAfterReset: (config, context) => {
    console.log('Form reset completed');
    
    // Analytics tracking
    analytics.track('form_reset', {
      formId: context.formId,
      resetType: config.resetType,
      fieldsCount: config.targetFields?.length || 0
    });
  }
}));
```

### Customization Options

| Option | Type | Description |
|--------|------|-------------|
| `onConfirm` | `(message: string, context: ActionExecutionContext) => Promise<boolean>` | Custom confirmation dialog |
| `onBeforeReset` | `(config: ResetConfig, context: ActionExecutionContext) => void` | Called before reset |
| `onAfterReset` | `(config: ResetConfig, context: ActionExecutionContext) => void` | Called after reset |

## Default Triggers

The Reset plugin responds to these triggers by default:
- `form_reset` - Triggered by reset buttons or manual calls

## Examples

### Basic Form Reset

```typescript
const actions = [
  {
    id: "reset-all",
    type: "reset_form",
    resetType: "all",
    confirmReset: true,
    triggers: ["reset_button_click"]
  }
];

// Form with reset button
<FormEngine
  config={formConfig}
  actions={actions}
  onReset={() => executeAction("reset-all")}
>
  <button type="button" onClick={() => executeAction("reset-all")}>
    Reset Form
  </button>
</FormEngine>
```

### Smart Reset with Auto-Save Recovery

```typescript
registerAction(resetPlugin({
  onBeforeReset: (config, context) => {
    // Save current state for recovery
    const formState = context.getFormState();
    const backupKey = `form-backup-${context.formId}-${Date.now()}`;
    
    localStorage.setItem(backupKey, JSON.stringify({
      state: formState,
      timestamp: Date.now(),
      resetType: config.resetType
    }));
    
    // Keep only last 5 backups
    const backups = Object.keys(localStorage)
      .filter(key => key.startsWith(`form-backup-${context.formId}`))
      .sort()
      .slice(0, -4);
    
    backups.forEach(key => localStorage.removeItem(key));
  },
  
  onAfterReset: (config, context) => {
    // Show undo option
    showNotification({
      message: "Form reset. Click here to undo.",
      variant: "info",
      duration: 10000,
      actions: [{
        label: "Undo",
        onClick: () => restoreLastBackup(context.formId)
      }]
    });
  }
}));

const actions = [
  {
    id: "smart-reset",
    type: "reset_form",
    resetType: "all",
    confirmReset: true,
    confirmMessage: "Reset form? You can undo this action for 10 seconds."
  }
];
```

## Accessibility Considerations

When implementing custom confirmation dialogs:

```typescript
registerAction(resetPlugin({
  onConfirm: async (message, context) => {
    // Ensure confirmation dialog is accessible
    return new Promise((resolve) => {
      const dialog = document.createElement('div');
      dialog.setAttribute('role', 'alertdialog');
      dialog.setAttribute('aria-labelledby', 'reset-title');
      dialog.setAttribute('aria-describedby', 'reset-message');
      dialog.setAttribute('aria-modal', 'true');
      
      dialog.innerHTML = `
        <h2 id="reset-title">Confirm Reset</h2>
        <p id="reset-message">${message}</p>
        <button onclick="resolve(false)">Cancel</button>
        <button onclick="resolve(true)" autofocus>Reset</button>
      `;
      
      // Focus management
      document.body.appendChild(dialog);
      dialog.querySelector('button[autofocus]')?.focus();
      
      // Handle resolve
      dialog.addEventListener('click', (e) => {
        if (e.target.tagName === 'BUTTON') {
          resolve(e.target.textContent === 'Reset');
          document.body.removeChild(dialog);
        }
      });
    });
  }
}));
```
