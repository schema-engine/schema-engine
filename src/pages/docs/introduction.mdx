# Introduction

Welcome to Form Engine - a comprehensive, type-safe form rendering system designed for modern React applications. Form Engine eliminates the complexity of building dynamic forms by providing a declarative, configuration-driven approach that scales from simple contact forms to complex multi-step wizards.

## What is Form Engine?

Form Engine is a React-based form system that transforms JSON configurations into fully functional, interactive forms. Built on top of React Hook Form and Zod, it provides:

- **Declarative Configuration**: Define forms using JSON instead of writing imperative React components
- **Type Safety**: Full TypeScript support with automatic type inference and validation
- **Performance**: Optimized rendering with minimal re-renders and tree-shakable components
- **Flexibility**: Extensible architecture that adapts to any use case

## Core Philosophy

### Configuration Over Code

Instead of writing form components manually, you define the structure, validation, and behavior in a JSON configuration:

```typescript
const formConfig = {
  id: "user-profile",
  title: "User Profile",
  steps: [
    {
      title: "Personal Information",
      fields: [
        {
          type: "input",
          name: "firstName",
          label: "First Name",
          validation: [{ type: "required" }]
        },
        {
          type: "input",
          name: "email",
          label: "Email Address",
          validation: [
            { type: "required" },
            { type: "email" }
          ]
        }
      ]
    }
  ]
};
```

### Type Safety Throughout

Form Engine provides complete type safety from configuration to runtime:

- **Configuration Types**: Strongly typed form configs with discriminated unions
- **Validation Schema**: Automatic Zod schema generation from validation rules
- **Runtime Safety**: Runtime validation of configurations and form data
- **Developer Experience**: Full IntelliSense and compile-time error checking

### Performance by Design

Built with performance as a first-class concern:

- **Minimal Re-renders**: Strategic use of React Hook Form's `useWatch`
- **Tree Shaking**: Only imported field components are bundled
- **Lazy Loading**: Components and validation load as needed
- **Memory Management**: Proper cleanup and resource management

```
                              │
                              ▼
                    ┌─────────────────┐

                    │ • Validators    │

                    └─────────────────┘
```

## When to Use Form Engine

Form Engine is ideal for applications that need:

### ✅ Perfect Fit

- **Dynamic Forms**: Forms that change based on user input or external data
- **Multi-Step Workflows**: Registration flows, surveys, wizards
- **Consistent UI**: Standardized form appearance across your application
- **Complex Validation**: Conditional validation rules and cross-field dependencies
- **Responsive Design**: Forms that work perfectly on all device sizes
- **Developer Productivity**: Teams that want to move fast without sacrificing quality

### ❌ Consider Alternatives

- **Simple Static Forms**: Basic contact forms might be overkill
- **Highly Custom UI**: Forms requiring pixel-perfect custom designs
- **Non-React Applications**: Form Engine is React-specific
- **Minimal Bundle Size**: If every KB matters and you only need basic forms
