# Introduction

Form Engine is a powerful, type-safe form rendering system built for React applications. It provides a declarative, configuration-driven approach to building complex forms while maintaining full type safety and extensibility.

## See It In Action

Here's a simple example showing Form Engine's core concept - configuration-driven forms with built-in validation:

## What Makes Form Engine Different?

**Configuration-Driven**: Define forms using JSON-like configuration objects instead of writing repetitive JSX components.

**Type-Safe**: Full TypeScript support with automatic type inference and validation using Zod schemas.

**Responsive by Design**: Built-in CSS Grid system with mobile-first responsive breakpoints.

**Action-Oriented**: Extensible action system for handling submissions, auto-saving, analytics, and custom behaviors.

**Conditional Logic**: Dynamic field visibility and behavior based on other field values.

## Architecture Overview

Form Engine uses a modular architecture with several key components:

```
Form Engine
├── Core
│   ├── FormRenderer - Main rendering component
│   ├── FieldRenderer - Individual field rendering
│   └── Provider - Context and state management
├── Grid System
│   ├── GridContainer - Responsive grid layout
│   └── Grid Hooks - Responsive behavior logic
├── Validation
│   ├── Zod Integration - Schema validation
│   └── ValidationPresets - Common validation rules
├── Actions
│   ├── ActionExecutor - Action orchestration
│   └── Plugins - Submit, reset, auto-save, analytics
└── Types
    ├── Form Configuration - Type definitions
    └── Field Configurations - Field-specific types
```

## Design Principles

**Developer Experience**: Minimal boilerplate with maximum flexibility. Define complex forms with simple configuration objects.

**Type Safety**: Comprehensive TypeScript support with automatic type inference from Zod schemas.

**Performance**: Efficient rendering with React Hook Form integration and optimized re-renders.

**Accessibility**: Built-in ARIA support and keyboard navigation (expanding).

**Extensibility**: Plugin-based architecture for custom field types, validation rules, and actions.

## Getting Started

The fastest way to understand Form Engine is through examples. Here's a simple contact form:

```typescript
import { FormRenderer } from "@/lib/form-engine";
import { ValidationPresets } from "@/lib/form-engine/validation";

const contactForm = {
  id: "contact",
  title: "Contact Us",
  autoGenerateSchema: true,
  steps: [{
    id: "details",
    fields: [
      {
        type: "input",
        inputType: "text",
        id: "name",
        name: "name",
        label: "Full Name",
        validation: [ValidationPresets.required("Name is required")]
      },
      {
        type: "input", 
        inputType: "email",
        id: "email",
        name: "email",
        label: "Email",
        validation: [
          ValidationPresets.required("Email is required"),
          ValidationPresets.email("Please enter a valid email")
        ]
      }
    ]
  }]
};

export function ContactForm() {
  return (
    <FormRenderer 
      config={contactForm}
      onSubmit={(data) => console.log("Submitted:", data)}
    />
  );
}
```

This creates a fully functional form with validation, accessibility, and responsive design - all from a simple configuration object.
