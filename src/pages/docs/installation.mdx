## Package Installation

Install Form Engine and its peer dependencies using your preferred package manager:

### Using npm

```bash
npm install react-hook-form zod @hookform/resolvers
```

### Using Yarn

```bash
yarn add react-hook-form zod @hookform/resolvers
```

### Using pnpm

```bash
pnpm add react-hook-form zod @hookform/resolvers
```

### Using Bun

```bash
bun add react-hook-form zod @hookform/resolvers
```

## Peer Dependencies

Form Engine requires these peer dependencies:

| Package | Version | Purpose |
|---------|---------|---------|
| `react-hook-form` | `^7.43.0` | Form state management and validation |
| `zod` | `^3.20.0` | Schema validation and type inference |
| `@hookform/resolvers` | `^3.0.0` | Zod integration for React Hook Form |

## TypeScript Configuration

Form Engine is built with TypeScript and requires proper configuration for optimal experience.

### tsconfig.json

Ensure your `tsconfig.json` includes these settings:

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["DOM", "DOM.Iterable", "ES2020"],
    "module": "ESNext",
    "moduleResolution": "node",
    "strict": true,
    "jsx": "react-jsx",
    "declaration": true,
    "declarationMap": true,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "allowSyntheticDefaultImports": true,
    "forceConsistentCasingInFileNames": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

### Path Mapping

Form Engine uses path aliases for imports. Configure your bundler to resolve these paths:

**Vite (vite.config.ts):**
```typescript
import { defineConfig } from 'vite';
import { resolve } from 'path';

export default defineConfig({
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),
    },
  },
});
```

**Next.js (next.config.js):**
```javascript
const nextConfig = {
  experimental: {
    // Enable if using app directory
  },
  webpack: (config) => {
    config.resolve.alias = {
      ...config.resolve.alias,
      '@': path.resolve(__dirname, 'src'),
    };
    return config;
  },
};
```

**Webpack (webpack.config.js):**
```javascript
module.exports = {
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src'),
    },
  },
};
```

## Styling Setup

Form Engine uses Tailwind CSS for styling. If you're not using Tailwind, you'll need to provide equivalent styles.

### Tailwind CSS

```bash
npm install tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

**tailwind.config.js:**
```javascript
module.exports = {
  content: [
    "./src/**/*.{js,jsx,ts,tsx}",
    "./node_modules/@/lib/form-engine/**/*.{js,jsx,ts,tsx}"
  ],
  theme: {
    extend: {},
  },
  plugins: [],
};
```

### CSS Variables

Add these CSS variables to your stylesheet:

```css
:root {
```

## Field Registry Setup

Form Engine uses a registry system for field components. Import the field types you need:

### Development Setup (All Fields)

For development convenience, import all field types:

```typescript
// src/main.tsx or src/App.tsx
import "@/components/form/registries";
```

### Production Setup (Tree-Shakable)

For optimal bundle size, import only the fields you use:

```typescript
// Import specific field types
import "@/components/form/registries/input.registry";
import "@/components/form/registries/select.registry";
import "@/components/form/registries/checkbox.registry";
import "@/components/form/registries/textarea.registry";
import "@/components/form/registries/number.registry";
import "@/components/form/registries/radio.registry";
import "@/components/form/registries/switch.registry";
import "@/components/form/registries/date.registry";
import "@/components/form/registries/file.registry";
import "@/components/form/registries/array.registry";
```

## Verification

Verify your installation by creating a simple form:

```typescript
// src/components/TestForm.tsx
import { FormRenderer } from "@/lib/form-engine";

const testConfig = {
  id: "test-form",
  title: "Installation Test",
  steps: [
    {
      title: "Test Step",
      fields: [
        {
          type: "input",
          name: "testField",
          label: "Test Field",
          validation: [{ type: "required" }]
        }
      ]
    }
  ]
};

export function TestForm() {
  const handleSubmit = (data: any) => {
    console.log("Form submitted:", data);
  };

  return (
    <FormRenderer 
      config={testConfig} 
      onSubmit={handleSubmit}
    />
  );
}
```

If the form renders without errors, your installation is complete!

## Troubleshooting

### Common Issues

**Module Resolution Errors:**
- Ensure path aliases are configured in your bundler
- Check that `@` points to your `src` directory

**TypeScript Errors:**
- Verify TypeScript version is 4.5.0 or higher
- Ensure `strict` mode is enabled in tsconfig.json

**Missing Peer Dependencies:**
- Install all required peer dependencies
- Check for version compatibility issues

**Styling Issues:**
- Verify Tailwind CSS is properly configured
- Ensure CSS variables are defined

### Getting Help

If you encounter issues:

1. Check the [Troubleshooting Guide](/docs/guides/troubleshooting)
2. Review the [Examples](/docs/examples) for working configurations
3. Open an issue on [GitHub](https://github.com/your-org/form-engine)
