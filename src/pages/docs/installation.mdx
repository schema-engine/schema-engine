## Development Setup

Currently, to explore and contribute to Form Engine, you'll need to run the development environment:

### Prerequisites

- **Bun** - This project uses Bun as the JavaScript runtime
- **Node.js** 18+ (for compatibility)
- **Git** for cloning the repository

### Clone and Setup

```bash
# Clone the repository
git clone https://github.com/andeeplus/form-engine.git
cd form-engine

# Install dependencies
bun install

# Start development server
bun dev
```

The development server will start at `http://localhost:3000` with:
- **Live examples** and interactive demos
- **Documentation** with real-time updates
- **Component playground** for testing configurations

### Development Scripts

```bash
# Start development server with hot reload
bun dev

# Build for production
bun build  

# Start production server
bun start

# Preview production build
bun preview

# Run tests (when available)
bun test
```

## Project Structure

When exploring the codebase, here's how it's organized:

```
form-engine/
├── src/lib/form-engine/         # Core library source
│   ├── actions/                 # Action system
│   ├── components/              # Form components
│   ├── hooks/                   # Shared hooks
│   ├── types/                   # TypeScript definitions
│   └── index.ts                 # Public API
├── src/components/demo/         # Live examples
├── src/pages/docs/              # Documentation
└── test/                        # Test suites
```

## TypeScript Configuration

Form Engine is built with TypeScript-first approach. If you're using TypeScript, add these types to your `tsconfig.json`:

```json
{
  "compilerOptions": {
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "moduleResolution": "bundler",
    "jsx": "react-jsx"
  }
}
```

## Styling Requirements

Form Engine is designed to work with your existing styling solution:

### With Tailwind CSS (Recommended)

The default components use Tailwind CSS classes. Install Tailwind and include the base styles:

```bash
npm install tailwindcss @tailwindcss/forms
```

### With Custom CSS

Override the default styles by providing your own CSS classes or styled components.

### With Component Libraries

Use your existing component library by registering custom field components through the registry system.
