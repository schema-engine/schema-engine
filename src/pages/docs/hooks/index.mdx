# Form Engine Hooks

Form Engine provides a comprehensive set of React hooks that give you direct access to form state, field management, and powerful utilities. These hooks are designed to integrate seamlessly with React Hook Form while adding Form Engine-specific functionality.

## Core Hooks

### useFormContext
Access the complete form context and state from any component within a Form Engine form.

**[Learn more →](/docs/hooks/use-form-context)**

### useField  
Create and manage individual field state with automatic validation and grid integration.

**[Learn more →](/docs/hooks/use-field)**

### useActionExecutor
Execute actions programmatically and integrate with the action system.

**[Learn more →](/docs/hooks/use-action-executor)**

## State Management Hooks

### useConstraintLogic
Evaluate conditional logic and manage dynamic field visibility.

**[Learn more →](/docs/hooks/use-constraint-logic)**

### useFormActions
Access form-level actions like submit, reset, and validation.

**[Learn more →](/docs/hooks/use-form-actions)**

## Utility Hooks

### useDebounce
Debounce values for optimized auto-save and validation performance.

**[Learn more →](/docs/hooks/use-debounce)**

## Integration Hooks

### useGdprConsent
Handle GDPR consent management within forms.

**[Learn more →](/docs/hooks/use-gdpr-consent)**

### useGtmTracker
Integrate Google Tag Manager tracking with form events.

**[Learn more →](/docs/hooks/use-gtm-tracker)**

## Quick Reference

```typescript
import {
  useFormContext,
  useField,
  useActionExecutor,
  useConstraintLogic,
  useFormActions,
  useDebounce,
  useGdprConsent,
  useGtmTracker
} from '@/lib/form-engine/hooks';
import { ValidationPresets } from '@/lib/form-engine/validation';

// Access form context
const { formState, control, setValue } = useFormContext();

// Create a field
const nameField = useField('name', {
  rules: [
    ValidationPresets.required("Name is required")
  ],
  defaultValue: ''
});

// Execute actions
const { executeAction, isExecuting } = useActionExecutor();

// Handle conditional logic
const isVisible = useConstraintLogic({
  field: 'userType',
  operator: 'equals',
  value: 'premium'
});
```

*Each hook is designed to solve specific form challenges while maintaining type safety and performance.*
