# Responsive Grid System

Form Engine provides a powerful, CSS Grid-based responsive layout system that adapts seamlessly to any screen size. Built on modern CSS Grid with mobile-first cascade behavior, it offers precise control over form layouts while maintaining simplicity.

## See Grid Responsiveness in Action

Try resizing your browser window to see how the form adapts to different screen sizes:

</ViewportPreview>

## Grid Philosophy### Mobile-First Approach

The grid system follows a mobile-first philosophy where you define base styles for mobile devices and progressively enhance for larger screens:

```typescript
const mobileFirstGrid = {
  columns: 1,        // Base: single column on mobile
  gap: 16,          // Base: smaller gap on mobile
  responsive: {
    md: {
      columns: 2,    // Two columns on tablets
      gap: 24        // Larger gap on tablets
    },
    lg: {
      columns: 3,    // Three columns on desktop
      gap: 32        // Even larger gap on desktop
    }
  }
};
```

### Cascade Behavior

Values cascade upward like CSS media queries. If you don't define a value for a breakpoint, it inherits from the next smaller breakpoint:

```typescript
const cascadingGrid = {
  columns: 1,        // Used for default, sm (if not specified)
  responsive: {
    md: {
      columns: 2     // Used for md, lg, xl, 2xl (if not specified)
    }
    // lg inherits columns: 2 from md
    // xl inherits columns: 2 from md  
    // 2xl inherits columns: 2 from md
  }
};
```

## Breakpoint System

Form Engine uses a standard breakpoint system based on Tailwind CSS:

| Breakpoint | Min Width | Typical Device |
|------------|-----------|----------------|
| `default`  | 0px       | Mobile phones |
| `sm`       | 640px     | Large phones |
| `md`       | 768px     | Tablets |
| `lg`       | 1024px    | Small desktops |
| `xl`       | 1280px    | Large desktops |
| `2xl`      | 1536px    | Extra large screens |

### Breakpoint Examples

```typescript
// Simple two-column layout
const simpleGrid = {
  columns: 1,
  responsive: {
    md: { columns: 2 }
  }
};

// Complex responsive grid
const complexGrid = {
  columns: 1,           // Mobile: 1 column
  gap: 16,             // Mobile: 16px gap
  responsive: {
    sm: {
      gap: 20          // Large mobile: larger gap
    },
    md: {
      columns: 2,      // Tablet: 2 columns
      gap: 24          // Tablet: even larger gap
    },
    lg: {
      columns: 3,      // Desktop: 3 columns
      gap: 32          // Desktop: largest gap
    },
    xl: {
      columns: 4       // Large desktop: 4 columns
      // Gap inherits 32px from lg
    }
  }
};
```

## Form-Level Grid Configuration

Set the overall grid layout for your entire form:

```typescript
const formConfig = {
  id: "responsive-form",
  title: "Responsive Contact Form",
  
  // Form-level grid configuration
  grid: {
    columns: 1,
    gap: 24,
    responsive: {
      md: {
        columns: 2,
        gap: 32
      },
      lg: {
        columns: 3
      }
    }
  },
  
  steps: [
    {
      title: "Contact Information",
      fields: [
        {
          type: "input",
          name: "firstName",
          label: "First Name"
        },
        {
          type: "input", 
          name: "lastName",
          label: "Last Name"
        },
        {
          type: "input",
          name: "email",
          label: "Email",
          // This field spans full width on all devices
          grid: { 
            colSpan: 3,
            responsive: {
              default: { colSpan: 1 },  // Full width on mobile
              md: { colSpan: 2 },       // Full width on tablet
              lg: { colSpan: 3 }        // Full width on desktop
            }
          }
        }
      ]
    }
  ]
};
```

## Step-Level Grid Configuration

Override grid settings for specific steps:

```typescript
const multiStepForm = {
  id: "multi-step-form",
  
  // Default grid for all steps
  grid: {
    columns: 1,
    responsive: {
      md: { columns: 2 }
    }
  },
  
  steps: [
    {
      title: "Personal Info",
      // Use default grid (2 columns on md+)
      fields: [
        { type: "input", name: "firstName", label: "First Name" },
        { type: "input", name: "lastName", label: "Last Name" }
      ]
    },
    {
      title: "Address",
      // Override with custom grid for this step
      grid: {
        columns: 1,
        responsive: {
          lg: { columns: 3 }  // 3 columns only on large screens
        }
      },
      fields: [
        { type: "input", name: "street", label: "Street Address" },
        { type: "input", name: "city", label: "City" },
        { type: "input", name: "zipCode", label: "ZIP Code" }
      ]
    }
  ]
};
```

## Field-Level Grid Configuration

Control individual field positioning and spanning:

```typescript
interface FieldGridConfig {
  colSpan?: number | "auto";    // How many columns to span
  rowSpan?: number | "auto";    // How many rows to span  
  colStart?: number;            // Starting column position
  colEnd?: number;              // Ending column position
  rowStart?: number;            // Starting row position
  rowEnd?: number;              // Ending row position
  responsive?: {                // Responsive overrides
    sm?: Partial<FieldGridConfig>;
    md?: Partial<FieldGridConfig>;
    lg?: Partial<FieldGridConfig>;
    xl?: Partial<FieldGridConfig>;
    "2xl"?: Partial<FieldGridConfig>;
  };
}
```

## Grid Utilities and Hooks

Form Engine provides utilities to work with the grid system:

### useFormGridStyles Hook

```typescript
import { useFormGridStyles } from "@/lib/form-engine";

function CustomFormContainer({ children, gridConfig }) {
  const styles = useFormGridStyles(gridConfig);
  
  return (
    <div className="form-container" style={styles}>
      {children}
    </div>
  );
}
```

### useFieldGridStyles Hook

```typescript
import { useFieldGridStyles } from "@/lib/form-engine";

function CustomField({ fieldConfig, children }) {
  const styles = useFieldGridStyles(fieldConfig.grid);
  
  return (
    <div className="form-field" style={styles}>
      {children}
    </div>
  );
}
```

### useCurrentBreakpoint Hook

```typescript
import { useCurrentBreakpoint } from "@/lib/form-engine";

function ResponsiveFormHeader() {
  const breakpoint = useCurrentBreakpoint();
  
  return (
    <h1 className={cn(
      "form-title",
      breakpoint === 'default' && "text-xl",
      breakpoint === 'md' && "text-2xl", 
      breakpoint === 'lg' && "text-3xl"
    )}>
      Form Title
    </h1>
  );
}
```

### Device Emulation

```typescript
const devicePresets = {
  mobile: { width: 375, height: 667 },
  tablet: { width: 768, height: 1024 },
  desktop: { width: 1440, height: 900 },
  ultrawide: { width: 1920, height: 1080 }
};

function DeviceEmulator({ device, children }) {
  const preset = devicePresets[device];
  
  return (
    <div 
      className="border rounded-lg overflow-hidden"
      style={{ width: preset.width, height: preset.height }}
    >
      {children}
    </div>
  );
}
```

## CSS Custom Properties

The grid system uses CSS custom properties that you can override:

```css
.form-container {
  --columns: 1;
  --gap: 1rem;
  --column-width: 1fr;
  
  display: grid;
  grid-template-columns: repeat(var(--columns), var(--column-width));
  gap: var(--gap);
}

/* Responsive overrides */
@media (min-width: 768px) {
  .form-container {
    --columns: 2;
    --gap: 1.5rem;
  }
}

@media (min-width: 1024px) {
  .form-container {
    --columns: 3;
    --gap: 2rem;
  }
}
```

## Best Practices

### 1. Start Mobile-First

```typescript
// ✅ Mobile-first approach
const grid = {
  columns: 1,           // Base mobile layout
  gap: 16,
  responsive: {
    md: { columns: 2 },  // Enhance for tablets
    lg: { columns: 3 }   // Enhance for desktop
  }
};

// ❌ Desktop-first approach
const grid = {
  columns: 3,           // Assumes desktop
  responsive: {
    md: { columns: 2 },  // Cramped on tablets
    sm: { columns: 1 }   // Afterthought for mobile
  }
};
```

### 2. Use Logical Field Spanning

```typescript
// ✅ Logical spanning based on content
{
  type: "textarea",
  name: "description",
  label: "Project Description",
  grid: { colSpan: 2 }  // Full width makes sense for long text
}

{
  type: "input",
  name: "zipCode",
  label: "ZIP Code",
  grid: { colSpan: 1 }  // Partial width makes sense for short text
}
```

### 3. Consider Content Hierarchy

```typescript
// ✅ Visual hierarchy with grid
const fields = [
  // Primary content - full width
  {
    type: "input",
    name: "title",
    label: "Project Title",
    grid: { colSpan: 2 }
  },
  
  // Secondary content - shared width
  {
    type: "input",
    name: "startDate",
    label: "Start Date",
    grid: { colSpan: 1 }
  },
  {
    type: "input",
    name: "endDate", 
    label: "End Date",
    grid: { colSpan: 1 }
  }
];
```

### 4. Test on Real Devices

```typescript
// Use realistic test scenarios
```
