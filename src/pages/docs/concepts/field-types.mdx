# Field Types

Form Engine provides a comprehensive set of field types to handle any form requirement. Each field type is designed with accessibility, usability, and flexibility in mind.

## Overview

Form Engine uses a type-safe, discriminated union system for field configuration. Each field type has its own specific properties while sharing common base properties.

```typescript
type FieldConfig = 
  | InputFieldConfig      // Text inputs, email, password, etc.
  | SelectFieldConfig     // Dropdowns and multi-select
  | CheckboxFieldConfig   // Boolean checkboxes
  | NumberFieldConfig     // Numeric inputs with constraints
  | TextareaFieldConfig   // Multi-line text areas
  | RadioFieldConfig      // Single-choice radio groups
  | SwitchFieldConfig     // Toggle switches
  | DateFieldConfig       // Date/time pickers
  | FileFieldConfig       // File uploads
  | ArrayFieldConfig;     // Dynamic arrays of fields
```

## Input Fields

Versatile text input fields supporting various input types.

### Configuration

```typescript
interface InputFieldConfig {
  type: "input";
  name: string;
  label?: string;
  inputType: "text" | "email" | "password" | "url" | "tel" | "search";
  placeholder?: string;
  maxLength?: number;
  minLength?: number;
  autoComplete?: string;
  validation?: ValidationRule[];
}
```

### Examples

```typescript
// Basic text input
{
  type: "input",
  name: "fullName",
  label: "Full Name",
  placeholder: "Enter your full name",
  validation: [{ type: "required" }]
}

// Email input with validation
{
  type: "input",
  name: "email",
  label: "Email Address",
  inputType: "email",
  placeholder: "john@example.com",
  autoComplete: "email",
  validation: [
    { type: "required" },
    { type: "email" }
  ]
}

// Password with constraints
{
  type: "input",
  name: "password",
  label: "Password",
  inputType: "password",
  validation: [
    { type: "required" },
    { type: "minLength", value: 8 },
    {
      type: "custom",
      message: "Password must contain uppercase, lowercase, and number",
      validator: (value) => /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/.test(value)
    }
  ]
}

// Phone number input
{
  type: "input",
  name: "phone",
  label: "Phone Number",
  inputType: "tel",
  placeholder: "+1 (555) 123-4567",
  validation: [
    {
      type: "pattern",
      value: "^\\+?[1-9]\\d{1,14}$",
      message: "Please enter a valid phone number"
    }
  ]
}
```

## Field Grid Configuration

All field types support grid-specific configuration for responsive layouts:

```typescript
interface FieldGridConfig {
  colSpan?: number | "auto";
  rowSpan?: number | "auto";
  colStart?: number;
  colEnd?: number;
  rowStart?: number;
  rowEnd?: number;
  responsive?: {
    sm?: Partial<FieldGridConfig>;
    md?: Partial<FieldGridConfig>;
    lg?: Partial<FieldGridConfig>;
    xl?: Partial<FieldGridConfig>;
    "2xl"?: Partial<FieldGridConfig>;
  };
}
```

### Grid Examples

```typescript
// Full-width field
{
  type: "textarea",
  name: "description",
  label: "Description",
  grid: { colSpan: 2 }
}

// Responsive field spanning
{
  type: "input",
  name: "title",
  label: "Title",
  grid: {
    colSpan: 1,
    responsive: {
      md: { colSpan: 2 },
      lg: { colSpan: 3 }
    }
  }
}

// Specific grid positioning
{
  type: "input",
  name: "featured",
  label: "Featured Item",
  grid: {
    colStart: 2,
    colEnd: 4,
    rowStart: 1
  }
}
```

## Best Practices

### 1. Choose Appropriate Field Types

```typescript
// ✅ Use specific input types
{ type: "input", inputType: "email", name: "email" }

// ❌ Generic text for email
{ type: "input", inputType: "text", name: "email" }
```

### 2. Provide Clear Labels and Help Text

```typescript
// ✅ Descriptive labels
{
  type: "input",
  name: "taxId",
  label: "Tax Identification Number",
  description: "Your business tax ID (e.g., 12-3456789)",
  placeholder: "12-3456789"
}
```

### 3. Use Appropriate Validation

```typescript
// ✅ Relevant validation rules
{
  type: "number",
  name: "age",
  validation: [
    { type: "required" },
    { type: "min", value: 0, message: "Age must be positive" },
    { type: "max", value: 120, message: "Please enter a valid age" }
  ]
}
```

### 4. Consider User Experience

```typescript
// ✅ Reasonable constraints
{
  type: "select",
  name: "country",
  searchable: true,          // Enable search for long lists
  placeholder: "Select...",  // Clear placeholder
  emptyOption: "None"        // Allow empty selection if optional
}
```
