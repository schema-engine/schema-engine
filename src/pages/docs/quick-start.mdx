## Basic Form Example

Here's how to create and render a simple form using Form Engine:

```typescript
import { FormRenderer } from "@/lib/form-engine";
import { ValidationPresets } from "@/lib/form-engine/validation";
import type { FormConfig } from "@/lib/form-engine/types";

const contactFormConfig: FormConfig = {
  id: "contact-form", 
  title: "Contact Us",
  autoGenerateSchema: true, // Automatically generates Zod schema from field validation
  steps: [{
    id: "contact-details",
    title: "Contact Information", 
    fields: [
      {
        type: "input",
        inputType: "text",
        id: "name",
        name: "name",
        label: "Full Name",
        placeholder: "Enter your full name",
        validation: [
          ValidationPresets.required("Name is required"),
          ValidationPresets.minLength(2, "Name must be at least 2 characters")
        ]
      },
      {
        type: "input", 
        inputType: "email",
        id: "email",
        name: "email", 
        label: "Email Address",
        placeholder: "Enter your email",
        validation: [
          ValidationPresets.required("Email is required"),
          ValidationPresets.email("Please enter a valid email")
        ]
      },
      {
        type: "textarea",
        id: "message", 
        name: "message",
        label: "Message",
        placeholder: "Your message...",
        rows: 4,
        validation: [
          ValidationPresets.required("Message is required"),
          ValidationPresets.minLength(10, "Message must be at least 10 characters")
        ]
      }
    ]
  }],
  actions: [
    {
      id: "contact-submit",
      type: "submit",
      description: "Submit contact form", 
      endpoint: "/api/contact",
      method: "POST",
      successMessage: "Thank you for your message!",
      errorMessage: "Failed to send message. Please try again.",
      enabled: true
    }
  ]
};

export function ContactForm() {
  const handleSubmit = (data: any) => {
    console.log("Form submitted:", data);
    // Handle form submission here
  };

  return (
    <FormRenderer 
      config={contactFormConfig} 
      onSubmit={handleSubmit}
    />
  );
}
```

## Configuration Structure

Understanding the basic structure of a form configuration:

### Required Properties

- `id` - Unique identifier for the form
- `steps` - Array of form steps (at least one required)

### Optional Properties

- `title` - Form title
- `description` - Form description
- `stepper` - Multi-step configuration
- `actions` - Form actions (submit, auto-save, etc.)
- `layout` - Responsive grid configuration

## Validation Rules

Built-in validation rules with automatic Zod schema generation:

### Basic Rules

- `required` - Field is required
- `email` - Valid email format
- `minLength` - Minimum string length
- `maxLength` - Maximum string length

### Advanced Rules

- `pattern` - Custom regex pattern
- `custom` - Custom validation function
- `min` - Minimum number value
- `max` - Maximum number value

## Validation

Form Engine uses Zod for type-safe validation with convenient presets:

```typescript
import { ValidationPresets } from "@/lib/form-engine/validation";

// Field with validation
{
  type: "input",
  inputType: "text",
  name: "username",
  label: "Username", 
  validation: [
    ValidationPresets.required("Username is required"),
    ValidationPresets.minLength(3, "Username must be at least 3 characters"),
    ValidationPresets.regex(/^[a-zA-Z0-9_]+$/, "Username can only contain letters, numbers, and underscores")
  ]
}
```

## Form Actions

Add powerful actions for submissions and side effects:

```typescript
// In your form config
{
  id: "my-form",
  // ... other config
  actions: [
    // Submit action
    {
      id: "form-submit",
      type: "submit",
      description: "Submit form data",
      endpoint: "/api/submit",
      method: "POST",
      successMessage: "Form submitted successfully!",
      errorMessage: "Submission failed. Please try again.",
      enabled: true
    },
    // Reset after successful submission
    {
      id: "reset-after-success", 
      type: "reset",
      enabled: true,
      triggers: ["submit_success"],
      resetToDefaults: true
    }
  ]
}
```

## Conditional Logic

Show/hide fields based on other field values:

```typescript
{
  type: "input",
  name: "address",
  label: "Address",
  constraints: [
    {
      field: "attendanceType",
      operator: "equals", 
      value: "in-person",
      action: "show"
    }
  ]
}
```

## Responsive Grid

Create responsive layouts with CSS Grid:

```typescript
const responsiveConfig: FormConfig = {
  id: "responsive-form",
  grid: {
    columns: 1,
    responsive: {
      default: { columns: 1, gap: "1rem" },    // Mobile
      md: { columns: 2, gap: "1.5rem" },       // Tablet
      lg: { columns: 3, gap: "2rem" }          // Desktop  
    }
  },
  steps: [{
    fields: [
      {
        type: "input",
        name: "firstName",
        grid: {
          responsive: {
            default: { column: "1 / -1" },  // Full width mobile
            md: { column: "1 / 2" }         // First column tablet+
          }
        }
      }
    ]
  }]
};
```
