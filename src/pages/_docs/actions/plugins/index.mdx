# Built-in Plugins

Form Engine comes with several built-in plugins that handle common form behaviors. Each plugin provides a specific action type with its own configuration options.

## Available Plugins

### [Submit Plugin](/docs/actions/plugins/submit)
Handles form submission to API endpoints with configurable request handling.

**Type:** `submit`  
**Default Triggers:** `form_submit`, `step_submit`

### [Notification Plugin](/docs/actions/plugins/notification)  
Displays user notifications with different styles and durations.

**Type:** `show_notification`  
**Default Triggers:** `form_submit`

### [Reset Plugin](/docs/actions/plugins/reset)
Resets form to initial state with optional user confirmation.

**Type:** `reset`  
**Default Triggers:** `manual_reset`

### [Auto-Save Plugin](/docs/actions/plugins/auto-save)
Automatically saves form data as drafts to prevent data loss.

**Type:** `auto_save`  
**Default Triggers:** `form_change`

### [GTM Plugin](/docs/actions/plugins/gtm)
Pushes analytics events to Google Tag Manager with form data inclusion options.

**Type:** `gtm_event`  
**Default Triggers:** `form_submit`

## Plugin Registration

All plugins must be registered before use:

```typescript
import { registerAction } from "@/lib/form-engine/actions/action-registry";
import { 
  submitPlugin, 
  notificationPlugin, 
  resetPlugin,
  autoSavePlugin,
  gtmPlugin
} from "@/lib/form-engine/actions/plugins";

// Register plugins with default configuration
registerAction(submitPlugin());
registerAction(notificationPlugin());
registerAction(resetPlugin());
registerAction(autoSavePlugin());
registerAction(gtmPlugin());
```

## Plugin Customization

Each plugin accepts a configuration object to customize its behavior:

```typescript
// Custom submit behavior
registerAction(submitPlugin({
  onSuccess: (data, context) => {
    console.log("Submit successful:", data);
    analytics.track("form_submitted", { formId: context.formId });
  },
  onError: (error, context) => {
    console.error("Submit failed:", error);
    Sentry.captureException(error);
  }
}));

// Custom notification handlers
registerAction(notificationPlugin({
  onSuccess: (message) => toast.success(message),
  onError: (message) => toast.error(message),
  onWarning: (message) => toast.warning(message),
  onInfo: (message) => toast.info(message)
}));

// Custom storage for auto-save
registerAction(autoSavePlugin({
  storage: {
    save: async (key, data) => await api.saveDraft(key, data),
    load: async (key) => await api.loadDraft(key),
    remove: async (key) => await api.deleteDraft(key)
  },
  onSave: (data, context) => {
    console.log(`Draft saved for ${context.formId}`);
  }
}));
```

## Quick Reference

| Plugin | Type | Purpose | Key Options |
|--------|------|---------|-------------|
| Submit | `submit` | Form submission | `endpoint`, `method`, `successMessage` |
| Notification | `show_notification` | User feedback | `message`, `variant`, `duration` |
| Reset | `reset` | Form reset | `confirmMessage`, `resetToDefaults` |
| Auto-Save | `auto_save` | Draft persistence | `interval`, `storageKey` |
| GTM | `gtm_event` | Analytics tracking | `eventName`, `eventData`, `includeFormData` |
