# Types API

Comprehensive TypeScript type definitions for the Form Engine library.

## Core Types

### FormConfig

The main configuration interface for defining forms.

```typescript
interface FormConfig {
  id: string;
  title?: string;
  description?: string;
  mode?: FormMode;
  layout?: LayoutConfig;
  elements: FieldConfig[];
  steps?: StepConfig[];
  validation?: ValidationConfig;
  actions?: ActionConfig[];
  styling?: StylingConfig;
  metadata?: Record<string, any>;
}
```

### FieldConfig

Configuration for individual form fields.

```typescript
interface FieldConfig {
```

### Type Guards

Utility functions for type checking.

```typescript
// Type guard functions
export function isFieldConfig(obj: any): obj is FieldConfig;
export function isValidationRule(obj: any): obj is ValidationRule;
export function isActionConfig(obj: any): obj is ActionConfig;
export function isFormEvent(obj: any): obj is FormEvent;

// Example implementation
function isFieldConfig(obj: any): obj is FieldConfig {
  return (
    typeof obj === 'object' &&
    obj !== null &&
    typeof obj.id === 'string' &&
    typeof obj.type === 'string' &&
    typeof obj.name === 'string'
  );
}
```

## Generic Types

### Type Parameters

Many interfaces support generic type parameters for better type safety.

```typescript
interface TypedFormConfig<T extends Record<string, any> = FormData> {
  id: string;
  elements: TypedFieldConfig<T>[];
  validation?: TypedValidationConfig<T>;
  onSubmit?: (data: T) => void | Promise<void>;
}

interface TypedFieldConfig<T> {
  name: keyof T;
  type: FieldType;
  validation?: TypedValidationRule<T>[];
}

// Usage
interface UserFormData {
  firstName: string;
  lastName: string;
  email: string;
  age: number;
}

const userFormConfig: TypedFormConfig<UserFormData> = {
  id: 'user-form',
  elements: [
    {
      name: 'firstName', // Type-safe field names
      type: 'text',
      rules: [/* type-safe validation */]
    }
  ]
};
```

This comprehensive type system ensures type safety throughout your Form Engine implementation while providing flexibility for customization and extension.
