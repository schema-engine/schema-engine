# Multi-Step Forms

Form Engine provides powerful support for multi-step forms with built-in navigation, step validation, and customizable stepper components. Multi-step forms are perfect for complex workflows like user registration, surveys, checkout processes, and data collection wizards.

## Interactive Stepper Demo

Experience different stepper styles and see how they handle navigation, validation, and user experience:

## Stepper Capabilities

The Form Engine stepper system offers several key capabilities:

### 1. Multiple Visual Styles
- **Default Stepper**: Traditional horizontal layout with step numbers and titles
- **Vertical Stepper**: Space-efficient design perfect for mobile and narrow layouts  
- **Minimal Stepper**: Clean design with free navigation and reduced visual elements

### 2. Smart Navigation
- **Controlled Navigation**: Enforce step-by-step progression with validation
- **Free Navigation**: Allow users to jump between completed steps
- **Validation on Next**: Automatically validate current step before proceeding

### 3. Flexible Positioning
- **Top Position**: Standard placement above form content
- **Left Position**: Side-by-side layout for vertical steppers
- **Custom Positioning**: Full control over stepper placement

### 4. Rich Step Information
- **Step Titles**: Clear labels for each step
- **Step Descriptions**: Additional context for users
- **Step Icons**: Visual indicators and branding
- **Step Numbers**: Sequential numbering with progress indication

## Basic Multi-Step Setup

Create a multi-step form by defining multiple steps and configuring the stepper behavior:

```typescript
const multiStepFormConfig = {
  id: "stepper-demo",
  title: "Multi-Step Form",
  mode: "wizard", // Enforces step-by-step progression
  steps: [
    {
      id: "step1",
      title: "Personal Information",
      description: "Tell us about yourself",
      icon: "👤",
      elements: [
        {
          type: "input",
          name: "firstName",
          label: "First Name",
          rules: [{ type: "required" }]
        },
        {
          type: "input",
          name: "lastName", 
          label: "Last Name",
          rules:ype: "required" }]
        }
      ]
    },
    {
      id: "step2",
      title: "Contact Details",
      description: "How can we reach you?",
      icon: "📧",
      elements: [
        {
          type: "input",
          inputType: "email",
          name: "email",
          label: "Email Address",
          rules:
            { type: "required" },
            { type: "email" }
          ]
        },
        {
          type: "input",
          inputType: "tel",
          name: "phone",
          label: "Phone Number",
          rules:ype: "required" }]
        }
      ]
    }
  ],
  
  // Stepper configuration
  stepper: {
    variant: "default",           // "default" | "minimal" | "pills"
    orientation: "horizontal",    // "horizontal" | "vertical"
    position: "top",              // "top" | "left" | "right"
    showStepNumbers: true,        // Show step numbers (1, 2, 3...)
    showStepTitles: true,         // Show step titles
    allowStepJumping: false,      // Allow clicking on future steps
    validateOnNext: true,         // Validate before proceeding
    buttons: {
      previous: {
        label: "Back",
        variant: "outline"
      },
      next: {
        label: "Continue", 
        variant: "default"
      },
      submit: {
        label: "Complete",
        variant: "default"
      }
    }
  }
};
```

## Navigation Control

The stepper system provides several navigation control options:

### Controlled Navigation
Enforce step-by-step progression with rules:

```typescript
stepper: {
  allowStepJumping: false,    // Users must complete steps in order
  validateOnNext: true,       // Validate current step before proceeding
  mode: "wizard"              // Wizard mode enforces linear progression
}
```

### Free Navigation
Allow users to move freely between steps:

```typescript
stepper: {
  allowStepJumping: true,     // Users can click any step
  validateOnNext: false,      // No validation required
  mode: "free"                // Free mode allows any navigation
}
```

### Custom Button Configuration
Customize navigation button appearance and behavior:

```typescript
stepper: {
  buttons: {
    previous: {
      label: "← Previous",
      variant: "outline",
      disabled: false
    },
    next: {
      label: "Continue →",
      variant: "default",
      loadingText: "Processing..."
    },
    submit: {
      label: "🎉 Complete",
      variant: "default",
      loadingText: "Submitting..."
    }
  }
}
```

## Step Validation

Control how and when steps are validated:

```typescript
const validatedFormConfig = {
  id: "wizard-form",
  steps: [
    {
      title: "Step 1",
      elements: [
        {
          type: "input",
          name: "email",
          label: "Email",
          rules:
            { type: "required" },
            { type: "email" }
          ]
        }
      ]
    },
    {
      title: "Step 2", 
      elements: [
        {
          type: "input",
          name: "phone",
          label: "Phone Number",
          rules:
            { type: "required" },
            {
              type: "custom",
              message: "Please enter a valid phone number",
              validator: (value) => /^\+?[\d\s\-\(\)]+$/.test(value)
            }
          ]
        }
      ]
    }
  ],
  stepper: {
    validateOnNext: true,     // Validate before moving to next step
    validateOnPrevious: false, // Don't validate when going back
    showErrors: true,         // Show validation errors immediately
    blockInvalidSteps: true   // Prevent navigation to invalid steps
  }
};
```

## Manual Stepper Control

For advanced use cases, use the stepper components directly:

```typescript
import { Stepper, FormRenderer } from "@/lib/form-engine";
import { useState } from "react";

function CustomMultiStepForm() {
  const [currentStep, setCurrentStep] = useState(0);
  const [formData, setFormData] = useState({});
  
  const handleStepChange = (newStep: number) => {
    // Custom validation or logic before step change
    if (validateCurrentStep()) {
      setCurrentStep(newStep);
    }
  };

  const handleNext = () => {
    if (currentStep < formConfig.steps.length - 1) {
      setCurrentStep(currentStep + 1);
    }
  };

  const handlePrevious = () => {
    if (currentStep > 0) {
      setCurrentStep(currentStep - 1);
    }
  };

  return (
    <div className="max-w-4xl mx-auto p-6">
      <Stepper 
        sections={formConfig.steps}
        currentStep={currentStep}
        onStepChange={handleStepChange}
      >
        <Stepper.Header 
          variant="default"
          orientation="horizontal"
          showStepNumbers={true}
          className="mb-8"
        />
        
        <Stepper.Content>
          <FormRenderer
            config={{
              ...formConfig,
              steps: [formConfig.steps[currentStep]]
            }}
            onSubmit={handleStepSubmit}
            onChange={setFormData}
            initialValues={formData}
          />
        </Stepper.Content>
        
        <Stepper.Navigation
          previousButton={{
            label: "Back",
            variant: "outline",
            disabled: currentStep === 0
          }}
          nextButton={{
            label: currentStep === formConfig.steps.length - 1 ? "Submit" : "Next",
            variant: "default"
          }}
          onPrevious={handlePrevious}
          onNext={handleNext}
          className="mt-6"
        />
      </Stepper>
    </div>
  );
}
```

## Advanced Stepper Customization

Create fully custom stepper components:

```typescript
import { StepperProvider, useStepperContext } from "@/lib/form-engine";

function CustomStepperHeader() {
  const { currentStep, sections, goToStep } = useStepperContext();
  
  return (
    <div className="flex items-center justify-between mb-8">
      {sections.map((section, index) => (
        <div key={index} className="flex items-center">
          <button
            onClick={() => goToStep(index)}
            className={cn(
              "w-10 h-10 rounded-full flex items-center justify-center",
              index === currentStep 
                ? "bg-blue-600 text-white" 
                : index < currentStep
                ? "bg-green-600 text-white"
                : "bg-gray-200 text-gray-600"
            )}
          >
            {index < currentStep ? "✓" : index + 1}
          </button>
          <span className="ml-2 text-sm font-medium">
            {section.title}
          </span>
          {index < sections.length - 1 && (
            <div className="mx-4 h-px bg-gray-300 flex-1" />
          )}
        </div>
      ))}
    </div>
  );
}

function CustomMultiStepForm() {
  return (

      <CustomStepperHeader />
      <StepperContent>
        {/* Form content */}
      </StepperContent>
      <StepperNavigation />
    </StepperProvider>
  );
}
```
